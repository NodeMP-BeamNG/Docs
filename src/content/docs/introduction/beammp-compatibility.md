NodeMP does not run BeamMP server plugins, and a BeamMP server cannot be moved to NodeMP as it is.

This page has been replaced by [Differences from BeamMP](/introduction/differences-from-beammp/).
To port a plugin, see [Migrating BeamMP plugins](/plugins/migrating/).
