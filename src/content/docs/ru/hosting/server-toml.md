Настройки сервера хранятся в одном файле, `server.toml`, в рабочей папке сервера. Каждый ключ с типом и значением по умолчанию описан в [справочнике настроек](/ru/hosting/configuration/).

## Как устроен файл

При первом запуске сервер пишет короткий файл с таблицами, которые заполняет хост: `[server]`, `[vehicles]` и `[listing]`.

```toml
# NodeMP server settings: https://docs.nodemp.com/hosting/configuration/
# Environment variables (NODE_PORT, NODE_NAME, ...) win over this file.

[server]
name = "Node Server"
port = 30814
max_players = 8
cars_per_player = 1
map = "/levels/gridmap_v2/info.json"
mods = "content"  # folder of mod zips players download

[vehicles]
queue = "allow"  # "off": every client applies at once (races, leagues)
queue_max_delay_sec = 0  # not 0: a client must apply within N s
edit_interval_sec = 5  # edits of one car reach the others at most once per N s
spawn_interval_sec = 2  # one player's new cars at most once per N s

[listing]
url = ""  # "https://api.nodemp.com" to be listed in the launcher
host_id = ""
host_secret = ""  # or NODE_DIRECTORY_HOST_SECRET, out of this file
description = ""
mode = "freeroam"
tags = ""
preview = ""  # a JPEG or PNG; empty: the map's own
public = true
guests = true  # players without a NodeMP account
```

- Настройка, которой нет в файле, остаётся по умолчанию. Чтобы изменить её, впишите её в свою таблицу, а если такой таблицы в файле ещё нет, добавьте и таблицу.
- Файл читается при запуске, поэтому после правки перезапустите сервер.
- Значение не того типа или вне допустимых пределов сервер не принимает: остаётся значение по умолчанию, а в логе появляется предупреждение. О незнакомом ключе сервер тоже предупреждает и называет его, так находятся опечатки.
- Таблица или ключ, записанные дважды, не дают серверу запуститься. Сообщение называет файл и строку ([Сервер не запускается](/ru/hosting/troubleshooting/#сервер-не-запускается)).
- Списки (`connection_limit_exempt`, `masked_commands`, `trusted`) можно писать строкой через запятую или списком TOML.

## Что меняют чаще всего

### Имя, карта и места

Это `name`, `map`, `max_players` и `cars_per_player` в `[server]`. Пример: [Запуск сервера](/ru/hosting/quick-start/#имя-карта-и-места).

### Порт

`[server] port` (по умолчанию `30814`) задаёт один порт и для TCP, и для UDP. Чтобы сервер слушал все адреса, IPv4 и IPv6, оставьте `address` равным `"::"`.

### Проверка файлов игры

`[integrity] verify` выбирает, насколько строго лаунчер проверяет файлы игры у игрока:

- `"off"`: сервер ничего не просит, но лаунчер всё равно проверяет `size`.
- `"size"`: размер каждого файла игры и лишние файлы в её `content/`. Значение по умолчанию.
- `"scripts"`: то же и контрольные суммы `lua/` и `ui/` игры. Ловит изменённые скрипты.
- `"full"`: контрольные суммы всей игры, около 50 ГБ, вместе с архивами. Это аудит, для проверки перед входом он слишком медленный.
- `"strict"`: то же, что `scripts`, и сверка оглавлений архивов, всей папки игры и папки пользователя с эталоном чистой установки ([Строгая проверка файлов](/ru/hosting/strict-verification/)).

### Место в списке серверов

За него отвечает таблица `[listing]`, в том числе ссылки на Discord, правила, сайт и голосовой чат сервера. Как её заполнить: [Попасть в список серверов](/ru/hosting/registering/).

### Чат

Чат встроен в сервер. `[chat] max_length`, `rate_per_sec` и `burst` ограничивают длину строки и то, как часто игрок может писать, чтобы чат не заваливали сообщениями.

### Машины других игроков

Клиентский мод придерживает чужие новые машины и правки, чтобы игра не замирала на перестройке посреди поворота, и каждый игрок сам решает, когда их применять ([как это выглядит у игрока](/ru/players/settings/#новые-машины-и-правки-других-игроков)). Для гонки или лиги, где все должны сразу видеть одни и те же машины, ожидание можно выключить или потребовать, чтобы всё строилось за заданное время:

```toml
[vehicles]
queue = "off"            # или: queue = "allow" и queue_max_delay_sec = 10
```

Плагин тоже может переключать это во время сессии и строить всё перед стартом ([Игроки и машины](/ru/plugins/players-and-vehicles/)). Число перестроек сокращают ещё `edit_interval_sec` и `spawn_interval_sec` ([Справочник настроек](/ru/hosting/configuration/#vehicles)).

### Плохие соединения

Игрок, который молчит `lag_grace_sec` секунд, считается отстающим, а через `disconnect_sec` его отключают ([Справочник настроек](/ru/hosting/configuration/#network)). Игрокам с мобильным интернетом или VPN можно дать больше времени:

```toml
[network]
disconnect_sec = 60
```

Больше 600 секунд ставить бесполезно: через 600 секунд лаунчер перестаёт пытаться вернуться. Таймеры должны идти по порядку, иначе сервер не запустится: `lag_grace_sec < seat_takeover_sec <= seat_release_sec <= disconnect_sec`, и `lag_grace_sec` не меньше 1.

## Переменные окружения

У каждой настройки есть своя переменная окружения, её имя указано в [справочнике настроек](/ru/hosting/configuration/). Переменная важнее файла, а `--port` в командной строке важнее их обеих. Секреты вроде `host_secret` лучше держать в окружении: так они не попадут в файл, который копируют и пересылают.

Несколько переменных к настройкам не относятся:

| Переменная | Что делает |
|---|---|
| `NODE_LUA` | Путь к Lua 5.1 для обфускатора. Нужна на Linux. |
| `NODE_TOOLS_DIR` | Другое место для папки `tools/`. |
| `NODE_PROVIDER_DISABLE_CONFIG` | `true` или `1` отключает чтение `server.toml`, всё берётся из окружения. Так работает Docker-образ. |
| `NODE_PROVIDER_IP_ENV`, `NODE_PROVIDER_PORT_ENV` | Для хостинг-панелей: имя переменной, в которой панель передаёт адрес и порт. |
| `NODE_HEARTBEAT_FILE` | Файл, который сервер обновляет, пока работает. По нему Docker проверяет здоровье контейнера. |
| `NODE_FORCE_ANSI` | `1` или `true` оставляет цвета, даже если вывод идёт не в терминал. |

## Командная строка

| Параметр | Что делает |
|---|---|
| `--config=FILE` | Какой файл настроек читать. По умолчанию `server.toml` в рабочей папке. Путь с пробелами берите в кавычки. |
| `--port=N` | Порт TCP и UDP. Важнее файла и окружения. |
| `--working-directory=DIR` | Рабочая папка: от неё считаются все относительные пути, в том числе путь из `--config`. |
| `--version` | Показать версию и выйти. |
| `--help` | Показать справку и выйти. |
| `--gen-integrity GAMEDIR` | Создать эталонный манифест для строгой проверки ([Строгая проверка файлов](/ru/hosting/strict-verification/#создать-манифест)). |
| `--bans list`, `--bans remove …` | Показать или снять баны, пока сервер остановлен ([Консоль, кики и баны](/ru/hosting/administration/#баны)). |
| `--obf-selftest` | Проверить, что обфускатор работает. |

Значение можно писать и через пробел: `--port 30815`. Чтобы запустить два сервера на одной машине, дайте каждому свою рабочую папку и свой порт:

```bash
./Node-Server --working-directory=/srv/nodemp-2 --port=30815
```
