`Node-Server` — программа, к которой подключаются игроки. Она работает на Windows, на Linux и в
Docker. Аккаунт для запуска не нужен: без него сервер просто не попадает в общий список, и игроки
заходят по адресу.

## Что понадобится

- Компьютер или VPS, до которого игроки достают по одному порту, TCP и UDP. По умолчанию это
  `30814`. Если сервер стоит дома, порт нужно пробросить на роутере.
- Windows x64 или Linux x64 уровня Ubuntu 24.04 и новее: сборке для Linux нужны glibc 2.38 и
  libstdc++ из GCC 13. На более старом Linux запускайте Docker-образ.
- Аккаунт на [nodemp.com](https://nodemp.com) — только если сервер должен появиться в списке.

## Пять шагов

1. **Скачайте и запустите сервер.** Инструкция под вашу систему: [Windows](/ru/hosting/windows/),
   [Linux](/ru/hosting/linux/) или [Docker](/ru/hosting/docker/).
2. **Откройте порт** `30814` для TCP и UDP. Команды для брандмауэра — на тех же страницах.
3. **Задайте имя, карту и число мест** — [ниже](#имя-карта-и-места).
4. **Добавьте сервер в список** с ключом сервера — [Попасть в список](/ru/hosting/registering/).
5. **Зайдите на него** из лаунчера — [ниже](#зайти-на-свой-сервер).

Сервер публикуется на [GitHub](https://github.com/NodeMP-BeamNG/releases/releases/tag/server-v1.13.0)
под тегом `server-v1.13.0`: архив для Windows, архив для Linux и Docker-образ, у каждого рядом файл
`.sha256` для проверки.

## Первый запуск

При первом запуске сервер создаёт короткий `server.toml` с настройками, которые хост обычно меняет,
TLS-сертификат и папки `content/` и `logs/`. Если всё в порядке, последние строки в консоли такие:

```
listening on [::]:30814 (tcp, tls 1.3, dual-stack: IPv4 + IPv6)
0 resources · 1 module loaded
server is ready
```

Предупреждение `no database configured` выше — это нормально. Модуль базы данных идёт вместе с
сервером и ждёт, пока он понадобится какому-нибудь плагину.

Остановить сервер можно сочетанием Ctrl+C или командой `stop` в его окне.

## Имя, карта и места

Откройте `server.toml` и поменяйте строки в таблице `[server]`:

```toml
[server]
name = "Вечерний фрирум"
map = "/levels/west_coast_usa/info.json"
max_players = 16
cars_per_player = 2
```

- `name` — имя сервера в списке и в игре.
- `map` — путь к файлу `info.json` карты: `/levels/<папка карты>/info.json`. Как поставить свою
  карту, рассказано в разделе [Моды и карты](/ru/hosting/mods/).
- `max_players` — сколько игроков могут быть на сервере одновременно.
- `cars_per_player` — сколько машин может держать один игрок.

Сервер читает файл только при запуске, так что после правки его нужно перезапустить. Сам он в этот
файл не пишет: ваши правки и комментарии останутся. Остальные настройки описаны на
странице [server.toml](/ru/hosting/configuration/). В Docker файла нет, там то же самое задают
переменными окружения.

## Зайти на свой сервер

Откройте лаунчер. Сервер с ключом виден во вкладке **Серверы** — найдите его по имени.

Сервер без ключа в списке не появится. Нажмите **Прямое подключение** и введите публичный адрес с
портом, например `203.0.113.10:30814`. С компьютера в той же домашней сети используйте локальный
адрес сервера, например `192.168.1.20:30814`.
