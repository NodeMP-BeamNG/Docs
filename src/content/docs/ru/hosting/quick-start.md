`Node-Server` — программа, к которой подключаются игроки. Она работает на Windows, на Linux и в Docker. Аккаунт для запуска не нужен: без него сервер не попадает в общий список, и игроки заходят по адресу.

## Что понадобится

- Компьютер или VPS, к которому игроки подключаются через один порт, по TCP и UDP. По умолчанию это `30814`. Если сервер стоит дома, пробросьте порт на роутере.
- Windows x64 или Linux x64. Что нужно Linux, сказано на странице [Сервер на Linux](/ru/hosting/linux/).
- Аккаунт на [nodemp.com](https://nodemp.com), если сервер должен появиться в списке.

## По шагам

1. Скачайте и запустите сервер. Архивы для Windows и Linux лежат на [странице загрузки](https://nodemp.com/download) в блоке **Свой сервер**, рядом контрольные суммы. Инструкции для каждой системы: [Windows](/ru/hosting/windows/), [Linux](/ru/hosting/linux/) или [Docker](/ru/hosting/docker/).
2. Откройте порт `30814` для TCP и UDP. Команды для брандмауэра есть на тех же страницах.
3. Задайте имя, карту и число мест ([ниже](#имя-карта-и-места)).
4. Добавьте сервер в список с ключом сервера: [Попасть в список](/ru/hosting/registering/).
5. Зайдите на него из лаунчера ([ниже](#зайти-на-свой-сервер)).

Те же файлы лежат на [GitHub](https://github.com/NodeMP-BeamNG/releases/releases) под тегом `server-v<версия>`: архив для Windows, архив для Linux и у каждого рядом файл `.sha256`.

## Первый запуск

При первом запуске сервер создаёт короткий `server.toml` с настройками, которые хост обычно меняет, TLS-сертификат и папки `content/` и `logs/`. Если всё в порядке, в консоли появятся строки:

```text
listening on [::]:30814 (udp, dual-stack: IPv4 + IPv6)
listening on [::]:30814 (tcp, tls 1.3, dual-stack: IPv4 + IPv6)
server is ready
```

Остановить сервер можно сочетанием Ctrl+C или командой `stop` в его окне.

## Имя, карта и места

Откройте `server.toml` и поменяйте строки в таблице `[server]`:

```toml
[server]
name = "Вечерний фрирум"
map = "/levels/west_coast_usa/info.json"
max_players = 16
cars_per_player = 2
```

Карта задаётся путём к её `info.json`: `/levels/<папка карты>/info.json`. Как поставить свою карту: [Моды и карты](/ru/hosting/mods/). `max_players` ограничивает число игроков на сервере, `cars_per_player` число машин у одного игрока.

Сохраните файл и перезапустите сервер. Остальные настройки описаны в [Настройке сервера](/ru/hosting/server-toml/) и в [справочнике настроек](/ru/hosting/configuration/). В Docker файла нет, там те же настройки задают переменными окружения ([Сервер в Docker](/ru/hosting/docker/)).

## Зайти на свой сервер

Сервер с ключом виден на вкладке **Серверы** в лаунчере. Сервер без ключа в списке не появится: нажмите **Прямое подключение** и введите публичный адрес с портом, например `203.0.113.10:30814` ([Как зайти на сервер](/ru/players/join/#подключиться-по-адресу)). С компьютера в той же домашней сети используйте локальный адрес сервера, например `192.168.1.20:30814`.
