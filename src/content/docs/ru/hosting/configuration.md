Ключи `server.toml` в том порядке, в каком их объявляет сервер. Строки пишутся в кавычках, как в файле. Как устроен файл, переменные окружения и командная строка: [Настройка сервера](/ru/hosting/server-toml/).

## `[server]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `name` | `NODE_NAME` | Имя сервера в списке и в игре. По умолчанию `"Node Server"`. |
| `port` | `NODE_PORT` | Порт TCP и UDP, к которому подключаются игроки. По умолчанию `30814`. |
| `max_players` | `NODE_MAX_PLAYERS` | Сколько игроков может быть на сервере одновременно. По умолчанию `8`. |
| `cars_per_player` | `NODE_MAX_CARS` | Сколько машин может быть у одного игрока. По умолчанию `1`. |
| `map` | `NODE_MAP` | Карта: путь к файлу `info.json`. По умолчанию `"/levels/gridmap_v2/info.json"`. |
| `mods` | `NODE_CONTENT_FOLDER` | Папка с zip-архивами модов, которые скачивают игроки. По умолчанию `"content"`. |
| `allow_client_mods` | `NODE_ALLOW_CLIENT_MODS` | Разрешить игрокам загружать клиентские моды из папки `mods` клиента. Варианты: `true`, `false`. По умолчанию `false`. |
| `address` | `NODE_IP` | Адрес, на котором сервер слушает. `"::"` — все адреса (IPv4 и IPv6). Это не публичный адрес сервера. По умолчанию `"::"`. |
| `console` | `NODE_CONSOLE` | Читать команды консоли со стандартного ввода (для каналов и файлов). Варианты: `true`, `false`. По умолчанию `false` (с терминалом включается сама). |

## `[vehicles]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `queue` | `NODE_VEHICLES_QUEUE` | Очередь чужих машин: `"allow"` (каждый игрок сам решает, придерживать ли новые машины) или `"off"` (строить сразу). По умолчанию `"allow"`. |
| `queue_max_delay_sec` | `NODE_VEHICLES_QUEUE_MAX_DELAY_SEC` | Максимальная задержка ожидания в очереди в секундах (до `3600`). `0` отключает принудительный сброс. По умолчанию `0`. |
| `edit_interval_sec` | `NODE_VEHICLES_EDIT_INTERVAL_SEC` | Минимальный интервал отправки правок машины другим игрокам в секундах. `0` отключает ограничение. По умолчанию `5`. |
| `spawn_interval_sec` | `NODE_VEHICLES_SPAWN_INTERVAL_SEC` | Минимальный интервал спавна новых машин одним игроком в секундах. `0` отключает ограничение. По умолчанию `2`. |

## `[listing]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `url` | `NODE_DIRECTORY_URL` | Адрес мастер-сервера списка: `"https://api.nodemp.com"`. Пустая строка убирает сервер из списка. По умолчанию `""`. |
| `host_id` | `NODE_DIRECTORY_HOST_ID` | Открытая часть ключа сервера в списке. |
| `host_secret` | `NODE_DIRECTORY_HOST_SECRET` | Секретная часть ключа сервера. Храните её как пароль. |
| `description` | `NODE_DIRECTORY_DESCRIPTION` | Одно-два предложения под именем сервера в списке. |
| `mode` | `NODE_DIRECTORY_MODE` | Режим игры (колонка в списке): `freeroam`, `racing`, `roleplay`, `drift` и другие. По умолчанию `"freeroam"`. |
| `tags` | `NODE_DIRECTORY_TAGS` | Теги через запятую для фильтрации в списке (до 8 штук). |
| `preview` | `NODE_DIRECTORY_PREVIEW` | Ссылка на картинку для списка. Пустая строка использует картинку карты. |
| `public` | `NODE_DIRECTORY_PUBLIC` | Показывать сервер в общем списке. Варианты: `true`, `false`. По умолчанию `true`. |
| `guests` | `NODE_DIRECTORY_TEST_DRIVE` | Пускать игроков без аккаунта. Варианты: `true`, `false`. По умолчанию `true`. |
| `fingerprint` | `NODE_DIRECTORY_FINGERPRINT` | Отпечаток сертификата для собственного списка серверов. Оставьте пустым. |
| `ca_file` | `NODE_DIRECTORY_CA_FILE` | Путь к CA-файлу для собственного списка серверов. Оставьте пустым. |
| `admit_when_down` | `NODE_DIRECTORY_REDEEM_FAIL_OPEN` | Если мастер-сервер недоступен: `true` пускает игроков как гостей, `false` отклоняет вход. Варианты: `true`, `false`. По умолчанию `false`. |
| `allow_http` | `NODE_DIRECTORY_ALLOW_INSECURE` | Разрешить незашифрованный `http://` в `url`. Варианты: `true`, `false`. По умолчанию `false`. |
| `discord` | `NODE_DIRECTORY_LINK_DISCORD` | Приглашение в Discord вашего сообщества. |
| `rules` | `NODE_DIRECTORY_LINK_RULES` | Ссылка на страницу с правилами сервера. |
| `site` | `NODE_DIRECTORY_LINK_SITE` | Ссылка на сайт сервера. |
| `donate` | `NODE_DIRECTORY_LINK_DONATE` | Ссылка на страницу поддержки и доната. |
| `voice` | `NODE_DIRECTORY_LINK_VOICE` | Ссылка на голосовой чат сервера. |

## `[integrity]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `verify` | `NODE_VERIFY_GAME` | Режим проверки файлов игры у игроков. Варианты: `off`, `size`, `scripts`, `full`, `strict`. По умолчанию `"size"`. |
| `manifests` | `NODE_INTEGRITY_DIR` | Папка с эталонными манифестами для режима `strict`. По умолчанию `"integrity"`. |
| `recheck_sec` | `NODE_INTEGRITY_RECHECK_SEC` | Периодичность повторной проверки файлов в режиме `strict` во время игры в секундах. `0` отключает проверку. По умолчанию `600`. |
| `auto_fetch` | `NODE_INTEGRITY_AUTO_FETCH` | Скачивать ли официальный манифест с бэкенда при отсутствии локальных файлов в папке манифестов в режиме `strict`. Варианты: `true`, `false`. По умолчанию `true`. |
| `url` | `NODE_INTEGRITY_URL` | Адрес бэкенда для загрузки официальных манифестов. По умолчанию используется `[listing] url` или `"https://api.nodemp.com"`. |
| `game_version` | `NODE_INTEGRITY_GAME_VERSION` | Версия игры для загрузки официального манифеста (например, `"0.39.4.0"`). По умолчанию пустая строка (загружается самая свежая версия). |

## `[network]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `tls_cert` | `NODE_TLS_CERT` | TLS-сертификат сервера. Создается автоматически при первом запуске. По умолчанию `"node_cert.pem"`. |
| `tls_key` | `NODE_TLS_KEY` | Закрытый ключ сертификата сервера. По умолчанию `"node_key.pem"`. |
| `relay_radius` | `NODE_STATE_RELAY_RADIUS` | Радиус отправки позиций машин в метрах. `0` отправляет позиции всем игрокам. По умолчанию `0`. |
| `lag_grace_sec` | `NODE_NETWORK_LAG_GRACE_SEC` | Время молчания игрока в секундах, после которого он считается отстающим. По умолчанию `8`. |
| `seat_takeover_sec` | `NODE_NETWORK_AUTH_TAKEOVER_SEC` | Время удержания места неактивным водителем в секундах перед передачей другому игроку. По умолчанию `10`. |
| `seat_release_sec` | `NODE_NETWORK_AUTH_RELEASE_SEC` | Время молчания в секундах, после которого сервер освобождает место водителя. По умолчанию `30`. |
| `disconnect_sec` | `NODE_NETWORK_DISCONNECT_SEC` | Время тишины в секундах перед отключением игрока и ожидание переподключения. По умолчанию `30`. |
| `send_queue_budget_mb` | `NODE_NETWORK_SEND_QUEUE_BUDGET_MB` | Лимит памяти в МБ на все исходящие очереди. `0` убирает общий лимит (остается 64 МБ на игрока). По умолчанию `256`. |
| `max_connections_per_ip` | `NODE_NETWORK_MAX_CONNECTIONS_PER_IP` | Лимит одновременных подключений в процессе входа с одного адреса. По умолчанию `32`. |
| `max_connections` | `NODE_NETWORK_MAX_CONNECTIONS` | Общий лимит одновременных подключений в процессе входа со всех адресов. По умолчанию `256`. |
| `connection_limit_exempt` | `NODE_NETWORK_CONNECTION_LIMIT_EXEMPT` | Подсети без лимита подключений на адрес (CIDR через запятую). По умолчанию локальные диапазоны. |
| `handshake_timeout_sec` | `NODE_NETWORK_HANDSHAKE_TIMEOUT_SEC` | Время в секундах на TLS-рукопожатие и начальные кадры авторизации. По умолчанию `20`. |
| `download_stall_sec` | `NODE_NETWORK_DOWNLOAD_STALL_SEC` | Таймаут прерывания загрузки мода при отсутствии переданных байтов в секундах. По умолчанию `60`. |

## `[queue]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `enabled` | `NODE_QUEUE_ENABLED` | Включить очередь ожидания при заполненном сервере. Варианты: `true`, `false`. По умолчанию `true`. |
| `max_waiting` | `NODE_QUEUE_MAX_WAITING` | Максимальная вместимость очереди (от `0` до `1000`). `0` отключает очередь. По умолчанию `50`. |
| `max_waiting_per_ip` | `NODE_QUEUE_MAX_WAITING_PER_IP` | Лимит ожидающих игроков с одного адреса (от `1` до `1000`). По умолчанию `1`. |
| `downloads_while_waiting` | `NODE_QUEUE_DOWNLOADS_WHILE_WAITING` | Сколько игроков в очереди скачивают моды одновременно (от `1` до `64`). По умолчанию `3`. |
| `max_no_shows` | `NODE_QUEUE_MAX_NO_SHOWS` | Лимит неявок за окно времени перед блокировкой входа в очередь. `0` отключает запрет. По умолчанию `3`. |
| `no_show_window_min` | `NODE_QUEUE_NO_SHOW_WINDOW_MIN` | Время окна учета неявок в минутах (от `1` до `10080`). По умолчанию `60`. |
| `no_show_bar_min` | `NODE_QUEUE_NO_SHOW_BAR_MIN` | Время временной блокировки очереди в минутах при превышении неявок. По умолчанию `30`. |

## `[chat]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `max_length` | `NODE_CHAT_MAX_LENGTH` | Максимальная длина сообщения в чате в байтах (от `16` до `2048`). По умолчанию `256`. |
| `rate_per_sec` | `NODE_CHAT_RATE_PER_SEC` | Лимит сообщений в секунду на игрока (не менее `1`). По умолчанию `2`. |
| `burst` | `NODE_CHAT_BURST` | Допустимый залп сообщений подряд перед ограничением частоты. По умолчанию `5`. |
| `log` | `NODE_CHAT_LOG_TO_CONSOLE` | Дублировать сообщения чата в консоль и лог сервера. Варианты: `true`, `false`. По умолчанию `true`. |
| `masked_commands` | `NODE_CHAT_LOG_HIDDEN_COMMANDS` | Команды через запятую, параметры которых маскируются в логах как `***`. По умолчанию команды авторизации. |

## `[logs]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `debug` | `NODE_DEBUG` | Подробный отладочный лог всех компонентов сервера. Варианты: `true`, `false`. По умолчанию `false`. |
| `details` | `NODE_LOG_DETAILS` | Выводить в консоль статистику и служебные строки (иначе идут только в файл). Варианты: `true`, `false`. По умолчанию `false`. |
| `max_size_mb` | `NODE_LOG_MAX_SIZE_MB` | Размер лог-файла в МБ для ротации в новый файл. `0` выполняет ротацию только при запуске. По умолчанию `50`. |
| `keep` | `NODE_LOG_KEEP` | Количество сохраняемых архивных файлов логов. По умолчанию `5`. |
| `date` | `NODE_LOG_DATE` | Добавлять дату перед временем в строках лога. Варианты: `true`, `false`. По умолчанию `false`. |
| `netstats_sec` | `NODE_NETWORK_STATS_INTERVAL_SEC` | Интервал записи сетевой статистики `netstats` в лог в секундах. `0` пишет только при выходе. По умолчанию `15`. |

## `[http]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `ca_file` | `NODE_HTTP_CA_FILE` | Путь к своему набору корневых сертификатов для HTTPS-запросов плагинов. |
| `insecure` | `NODE_HTTP_INSECURE` | Отключить проверку сертификатов в HTTPS-запросах плагинов. Варианты: `true`, `false`. По умолчанию `false`. |
| `allow_private_networks` | `NODE_HTTP_ALLOW_PRIVATE_NETWORKS` | Разрешить HTTP-запросам плагинов доступ к локальным адресам. Варианты: `true`, `false`. По умолчанию `false`. |

## `[resources]`

| Ключ | Переменная | Описание и варианты |
|---|---|---|
| `obfuscate` | `NODE_OBFUSCATE` | Обфусцировать клиентские скрипты плагинов перед отправкой игрокам. Варианты: `true`, `false`. По умолчанию `true`. |
| `trusted` | `NODE_RESOURCES_TRUSTED` | Доверенные плагины с полным доступом к системе Lua. `"*"` доверяет всем. Остальным доступна только своя папка. |
