description: Чем NodeMP отличается от BeamMP в аккаунтах, публикации, плагинах, транспорте и контенте — и почему сервер BeamMP нельзя перенести как есть.
---

Эта страница для тех, кто знает BeamMP. У NodeMP с ним общие корни: игровой сервер и хелпер
соединения начинались как форки кода BeamMP под лицензией AGPL-3.0-or-later, а синхронизация машин в
клиентском моде портирована из BeamMP. Всё вокруг этого ядра устроено иначе, и две сети не
взаимодействуют: лаунчер NodeMP подключается только к серверам NodeMP, а сервер NodeMP принимает
только лаунчер NodeMP.

## Сравнение

| Область | NodeMP | BeamMP |
|---|---|---|
| Аккаунты | Аккаунт NodeMP, созданный в лаунчере или на `https://nodemp.com` и используемый из лаунчера, либо гостевая сессия *Test Drive*, если сервер её разрешает. Сервер проверяет, кто вы, по одноразовому билету на подключение, выданному директорией. | Аккаунт форума BeamMP, вход через лаунчер BeamMP. |
| Публикация сервера | *Ключ сервера* (Host ID + Host secret), создаваемый один раз для каждого сервера на странице `/hosts` сайта nodemp.com и записываемый в секцию `[Directory]` файла `server.toml`. Сервер открывает сессию с директорией и отправляет маяк, чтобы оставаться в списке. | `AuthKey` из keymaster BeamMP, записываемый в `ServerConfig.toml`. |
| Конфигурация | `server.toml` с восемью секциями - `[General]`, `[Resources]`, `[Content]`, `[Network]`, `[Experimental]`, `[Directory]`, `[Database]` и `[Http]`; у каждого ключа есть переменная окружения `NODE_*` (см. [Конфигурацию](/ru/hosting/configuration/)). | `ServerConfig.toml` с секцией `[General]`. |
| Плагины | Ресурсы в `resources/`: Lua или JavaScript на сервере с API `node` (`node.on`, `node.players`, `node.vehicles`, `Player`, `Vehicle`, …), плюс нативные модули на C или C++. Плагины BeamMP на NodeMP не запускаются. | Lua-плагины в `Resources/Server` с API `MP.*` (`MP.RegisterEvent`, `MP.TriggerClientEvent`, …). |
| Клиентские скрипты | Ресурс содержит `client/*.lua`; сервер передаёт эти файлы каждому игроку при подключении, и они выполняются внутри игры с таблицей `node`. Локально установленные моды используют SDK `NodeMP.*`. | Клиентский Lua поставляется внутри zip-архивов клиентских модов. |
| Транспорт | TLS 1.3 поверх TCP между хелпером и сервером, UDP для потока позиций с аутентифицирующим трейлером; каждый пакет — типизированный кадр `(Category, SubType)`, сетевой протокол v18. Лаунчер с другой версией сервер отклоняет. | Обычные TCP и UDP с текстовыми метками пакетов. |
| Доставка контента | Zip-архивы в папке `content/` сервера, проверяемые хелпером по хешу и при желании шифруемые ChaCha20 при передаче (`[Content] Encrypt = true`). | Zip-архивы в `Resources/Client`, скачиваемые лаунчером. |
| Обфускация клиентского Lua | Передаваемый клиентский Lua по умолчанию обфусцируется Prometheus; каждый ресурс выбирает уровень `none`, `light`, `medium` или `strong` в своём `resource.toml`. | Не встроена. |

## Можно ли запустить мой сервер BeamMP на NodeMP?

Нет. `Node-Server` — другая программа с другим файлом конфигурации, другим ключом публикации и
другим API плагинов, и она не загружает плагины `MP.*`. Что можно перенести:

- **Карты и машины.** Положите zip-архивы в `content/`; сервер раздаст их подключающимся
  игрокам.
- **Логику плагинов.** Перенесите её на API `node`. Страница
  [Перенос плагинов BeamMP](/ru/plugins/migrating/) сопоставляет вызовы и события `MP.*` с их
  аналогами в NodeMP.
- **Игроков.** Они устанавливают лаунчер NodeMP ([Установить лаунчер](/ru/players/install/)) и
  находят ваш сервер в списке, как только у него появится ключ сервера
  ([Регистрация хоста](/ru/hosting/registering/)).
