В архиве сервера рядом с программой лежит папка `examples/`. Каждая папка в ней — готовый плагин. Список есть и в `examples/README.txt`.

## Что в папке

| Пример | Что показывает | Чему учит |
|---|---|---|
| `demo-numbers` | Самый маленький плагин с обеими частями: клиент раз в секунду шлёт число, сервер пишет его в лог. | Проверить, что клиентские скрипты доходят до игроков и отвечают. |
| `chat-commands` | `/help`, `/me` и `/pm`: роутер команд на `chatMessageRequest`. | Начать свои команды. |
| `freeroam-example` | Приветствия, событие клиента с ответом сервера, таймеры. | Небольшой плагин обычного вида. |
| `vehicle-cleanup` | Удаление машин, которыми никто не пользуется: простаивающих, брошенных хозяином, сверх общего лимита. | Правила из `[config]`. |
| `gatekeeper-example` | Отказ во входе, спавне и работе со сцепкой с причиной и наблюдение за правками, сбросами, покраской и удалением машин. | Как отказать в запросе и как следить за уведомлениями. |
| `seat-demo` | Посадка игроков по запросу из консоли игры: `SeatDemo.seat(gid)`, `SeatDemo.eject()`, `SeatDemo.swap()`. | `player:seat`, `player:unseat`, `player:swapWith`. |
| `nodegrab-allow` | Разрешение экспериментального захвата узлов, который без плагина запрещён. | Запрос, закрытый по умолчанию. |
| `devapi-example` | Обзор API, по одной возможности на событие клиента. | Увидеть вызов в деле, прежде чем читать справочник. |
| `session-report` | Кто играл, сколько и на чём; отчёт в JSON. Написан на JavaScript. | Готовый [плагин на JavaScript](/ru/plugins/js-host/). Нужен `js-host`. |

## Как установить

Скопируйте папку примера из архива в `resources/` и перезапустите сервер ([Поставить плагин](/ru/hosting/resources/#поставить-плагин)). Что делает пример, написано в комментариях в начале его `resource.toml` и `server/main.lua`. Настройки из `[config]` берёт только `vehicle-cleanup`.

## vehicle-cleanup

`vehicle-cleanup` удаляет машины, которые сервер оставляет в мире ([Игроки и машины](/ru/plugins/players-and-vehicles/#кто-есть-кто-в-машине)). Правила задаются в `[config]`, и в поставляемом `resource.toml` все они закомментированы, то есть выключены. Раскомментируйте нужные:

```toml
[config]
deleteIdleAfterSeconds = 600
deleteOnSpawnerDisconnect = true
maxWorldVehicles = 20
```

`includeUnicycles` решает, считаются ли пешеходы, а `checkIntervalMs` задаёт, как часто проверять правила.

## nodegrab-allow

Экспериментальному захвату узлов нужны две вещи: `[experimental] node_grab = true` в `server.toml` и плагин, который отвечает «да» на `vehicleNodeGrabRequest`. Без обработчика любой захват запрещён. `nodegrab-allow` и есть такой обработчик. Поменяйте его правила, чтобы разрешать захват только некоторым игрокам или машинам.

## Собираются из исходников, в архив не входят

Некоторые плагины — нативные модули. Они есть только в исходниках и собираются через CMake:

| Плагин | Что это |
|---|---|
| `js-host` | Запускает плагины на JavaScript ([Плагины на JavaScript](/ru/plugins/js-host/)). |
| `beammp-compat` | Запускает плагины, написанные для BeamMP, без изменений ([Переход с других платформ](/ru/plugins/migrating/#плагины-beammp-без-изменений)). |
| `dimensions` | Параллельные миры: игроки из разных измерений не видят друг друга. |
| `plugin-example` | Самый маленький рабочий нативный модуль, от него удобно начинать свой. |

Модуль базы данных `db` собирается так же, но поставляется вместе с сервером в `modules/` ([Модуль db](/ru/plugins/database/)).
