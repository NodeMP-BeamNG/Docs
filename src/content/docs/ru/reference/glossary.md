Документация называет каждую вещь одним словом. Здесь эти слова, английский вариант в скобках и страница, где о них подробнее. Если программа пишет другое слово, это сказано в строке.

## Игрокам

| Слово | Что значит | Подробнее |
|---|---|---|
| Лаунчер (launcher) | Программа для Windows, через которую вы входите в аккаунт, выбираете сервер и подключаетесь. Сама обновляется и ставит клиентский мод. | [Установка лаунчера](/ru/players/install/) |
| Помощник (helper) | Фоновая часть лаунчера без окна: запускает игру, держит связь с сервером и передаёт трафик, пока вы играете. В интерфейсе это «сетевой помощник лаунчера», а его лог называется `launcher.log`. | [Если что-то не работает](/ru/players/troubleshooting/#сетевой-помощник-лаунчера) |
| Клиентский мод (client mod) | `NodeMP.zip`, мод BeamNG, который делает всю мультиплеерную работу внутри игры. Его ставит и обновляет лаунчер. | [Установка лаунчера](/ru/players/install/#клиентский-мод) |
| Моды сервера (content) | Zip-архивы, которые сервер раздаёт игрокам. В лаунчере они называются «Контент». | [Моды и карты](/ru/hosting/mods/) |
| Аккаунт (account) | Аккаунт на nodemp.com. Даёт постоянное имя, которое проверяют серверы. | [Аккаунт и вход](/ru/players/sign-in/) |
| **Test Drive** | Игра без аккаунта под гостевым именем вида `Guest-7K3MQ`, которое не меняется, пока вы входите с той же установки лаунчера. О режиме говорят «Test Drive», об игроке «гость». | [Аккаунт и вход](/ru/players/sign-in/#test-drive) |
| Список серверов (server list) | Серверы, которые сейчас работают и сообщили о себе NodeMP. В лаунчере это вкладка **Серверы**, на сайте nodemp.com/servers. | [Как зайти на сервер](/ru/players/join/) |
| **Прямое подключение** (Direct Connect) | Вход по адресу `адрес:порт`, а не из списка. | [Как зайти на сервер](/ru/players/join/#подключиться-по-адресу) |
| **Зажмите для игры** (Hold to play) | Кнопка входа: её нужно подержать, чтобы не зайти случайно. Если удержание выключено, она называется **Играть**. | [Как зайти на сервер](/ru/players/join/#вход-на-сервер) |
| Строгий сервер (strict server) | Сервер с `[integrity] verify = "strict"`: сверяет вашу игру и папку пользователя с чистой установкой. | [Если что-то не работает](/ru/players/troubleshooting/#строгий-сервер-не-пускает) |
| Строгая сессия (strict session) | Клиентские правила, которые плагин сервера включает на время сессии: игра возвращает свободную камеру в машину, закрывает консоль и редактор, отменяет паузу, не пускает в машину, в которую сервер не посадил, и выключает локальные моды. Со строгим сервером не связана: тот проверяет файлы, а строгая сессия ограничивает игру. | [Строгие сессии](/ru/plugins/client-scripting/#строгие-сессии) |

## Хостам

| Слово | Что значит | Подробнее |
|---|---|---|
| Хост (host) | Человек, который держит сервер. Не «хостер». | [Запуск сервера](/ru/hosting/quick-start/) |
| Рабочая папка (working directory) | Папка, в которой сервер ищет `server.toml`, `resources/` и `content/` и пишет `logs/`: та, из которой его запустили, или та, что задана в `--working-directory`. | [Настройка сервера](/ru/hosting/server-toml/) |
| Ключ сервера (server key) | Host ID и Host secret из аккаунта на nodemp.com. С ним сервер попадает в список. | [Попасть в список серверов](/ru/hosting/registering/) |
| Отпечаток (fingerprint) | SHA-256 TLS-сертификата сервера. По нему лаунчеры узнают сервер. | [Попасть в список серверов](/ru/hosting/registering/#отпечаток-сервера) |
| Эталонный манифест (reference manifest) | Описание чистой установки BeamNG одной версии, по которому строгий сервер проверяет игроков. | [Строгая проверка файлов](/ru/hosting/strict-verification/) |
| Обфускация (obfuscation) | Запутывание клиентских скриптов плагинов перед отправкой игрокам. Делает её Prometheus из папки `tools/`. | [Плагины на сервере](/ru/hosting/resources/#обфускация-клиентских-скриптов) |

## Авторам плагинов

| Слово | Что значит | Подробнее |
|---|---|---|
| Плагин (plugin, resource) | Всё, чем расширяют сервер: папка в `resources/` с серверной частью на Lua (или другом языке) и, по желанию, клиентскими скриптами либо нативный модуль. | [Обзор](/ru/plugins/overview/) |
| Ресурс (resource) | Слово из кода, не название плагина: так называются папка `resources/`, файл `resource.toml`, `node.resources`, таблица `[resources]` и событие `resourceUnload`. Плагин в такой папке в тексте остаётся плагином, а «ресурс» пишем только там, где имеется в виду имя из кода. В английской документации то же слово — resource. | [Устройство плагина](/ru/plugins/resources/) |
| Нативный модуль (native module) | Библиотека `.dll` или `.so` в папке `modules/` рядом с программой сервера, работает через C ABI. | [Нативные модули](/ru/plugins/native-modules/) |
| C ABI | Двоичный интерфейс между сервером и нативными модулями, описан в `node.h`. Версия записывается как «старшая.младшая». | [Нативные модули](/ru/plugins/native-modules/) |
| Языковой хост (language host) | Нативный модуль, который запускает плагины своего `type`, например `js-host` для JavaScript. | [Плагины на JavaScript](/ru/plugins/js-host/) |
| Событие (event) | То, на что подписываются через `node.on`: события сервера, запросы, которые можно отклонить, и сетевые события от клиентов. | [События](/ru/plugins/events/) |
| Сетевое событие (wire event) | Именованное сообщение между клиентским скриптом и сервером, имя вида `область:глагол`. | [Клиентские скрипты](/ru/plugins/client-scripting/) |
| Шина (bus) | Канал между плагинами одного сервера: `node.bus.emit` и `node.bus.on`. | [Шина между плагинами](/ru/plugins/bus/) |
| Ретрансляция (relay) | Пересылка трафика одного игрока остальным. Её можно фильтровать для отдельных получателей. | [Нативные модули](/ru/plugins/native-modules/) |
| Водитель, авторитет, спавнер (driver, authority, spawner) | Спавнер создал машину. Водитель сидит за рулём. Авторитет — игрок, чья игра считает машину и рассылает её состояние, обычно это водитель. | [Игроки и машины](/ru/plugins/players-and-vehicles/) |
