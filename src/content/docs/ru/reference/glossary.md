Документация называет каждую вещь одним словом. Здесь эти слова, английский вариант в скобках и
страница, где о них подробнее. Если программа пишет другое слово, это сказано в строке.

## Игрокам

| Слово | Что значит | Подробнее |
|---|---|---|
| **Лаунчер** (launcher) | Программа для Windows, через которую вы входите в аккаунт, выбираете сервер и подключаетесь. Сама обновляется и ставит клиентский мод. | [Установка лаунчера](/ru/players/install/) |
| **Помощник** (helper) | Фоновая часть лаунчера без окна: запускает игру, говорит с сервером и передаёт трафик, пока вы играете. В интерфейсе — «сетевой помощник лаунчера», его лог — `launcher.log`. | [Если что-то не работает](/ru/players/troubleshooting/#сетевой-помощник-лаунчера) |
| **Клиентский мод** (client mod) | `NodeMP.zip` — мод BeamNG, который делает всю мультиплеерную работу внутри игры. Его ставит и обновляет лаунчер. | [Установка лаунчера](/ru/players/install/#клиентский-мод) |
| **Моды сервера** (content) | Zip-архивы, которые сервер раздаёт игрокам. Лаунчер называет их «Контент». | [Моды и карты](/ru/hosting/mods/) |
| **Аккаунт** (account) | Аккаунт на nodemp.com. Даёт постоянное имя, которое проверяют серверы. | [Аккаунт и вход](/ru/players/sign-in/) |
| **Test Drive** | Игра без аккаунта, под новым гостевым именем `Guest…` в каждой сессии. О режиме говорят «Test Drive», об игроке — «гость». | [Аккаунт и вход](/ru/players/sign-in/#test-drive) |
| **Список серверов** (server list) | Серверы, которые сейчас работают и сообщили о себе NodeMP. В лаунчере — вкладка **Серверы**, на сайте — nodemp.com/servers. | [Как зайти на сервер](/ru/players/join/) |
| **Прямое подключение** (Direct Connect) | Вход по адресу `адрес:порт`, а не из списка. | [Как зайти на сервер](/ru/players/join/#подключиться-по-адресу) |
| **Зажмите для игры** (Hold to play) | Кнопка входа: её нужно подержать, чтобы не зайти случайно. | [Как зайти на сервер](/ru/players/join/#войти) |
| **Строгий сервер** (strict server) | Сервер с `VerifyGame = "strict"`: сверяет вашу игру и папку пользователя с чистой установкой. | [Если что-то не работает](/ru/players/troubleshooting/#строгий-сервер-не-пускает) |

## Хостам

| Слово | Что значит | Подробнее |
|---|---|---|
| **Хост** (host) | Человек, который держит сервер. Не «хостер». | [Запуск сервера](/ru/hosting/quick-start/) |
| **Рабочая папка** (working directory) | Папка, из которой запущен сервер. В ней `server.toml`, `resources/`, `content/`, `logs/`. | [Настройки сервера](/ru/hosting/configuration/) |
| **Ключ сервера** (server key) | Host ID и Host secret из аккаунта на nodemp.com. С ним сервер попадает в список. | [Попасть в список](/ru/hosting/registering/) |
| **Отпечаток** (fingerprint) | SHA-256 TLS-сертификата сервера. По нему лаунчеры узнают сервер. | [Попасть в список](/ru/hosting/registering/#отпечаток-сервера) |
| **Эталонный манифест** (reference manifest) | Описание чистой установки BeamNG одной версии, по которому строгий сервер проверяет игроков. | [Строгая проверка](/ru/hosting/strict-verification/) |
| **Обфускация** (obfuscation) | Запутывание клиентских скриптов ресурсов перед отправкой игрокам. Делает её Prometheus из папки `tools/`. | [Ресурсы](/ru/hosting/resources/#обфускация-клиентских-скриптов) |

## Авторам плагинов

| Слово | Что значит | Подробнее |
|---|---|---|
| **Плагин** (plugin) | Всё, чем расширяют сервер: ресурс или нативный модуль. | [Обзор](/ru/plugins/overview/) |
| **Ресурс** (resource) | Папка в `resources/`: серверная часть на Lua (или другом языке) и, по желанию, клиентские скрипты. | [Устройство ресурса](/ru/plugins/resources/) |
| **Нативный модуль** (native module) | Библиотека `.dll` или `.so` в `modules/`, работает через C ABI. | [Нативные модули](/ru/plugins/native-modules/) |
| **C ABI** | Двоичный интерфейс между сервером и нативными модулями, описан в `node.h`. Версия — «старшая.младшая». | [Нативные модули](/ru/plugins/native-modules/) |
| **Языковой хост** (language host) | Нативный модуль, который запускает ресурсы своего `type`, например `js-host` для JavaScript. | [Ресурсы на JavaScript](/ru/plugins/js-host/) |
| **Событие** (event) | То, на что подписываются через `node.on`: события сервера, запросы, которые можно отклонить, и сетевые события от клиентов. | [События](/ru/plugins/events/) |
| **Сетевое событие** (wire event) | Именованное сообщение между клиентским скриптом и сервером, имя вида `область:глагол`. | [Клиентские скрипты](/ru/plugins/client-scripting/) |
| **Шина** (bus) | Канал между ресурсами одного сервера: `node.bus.emit` и `node.bus.on`. | [Шина между ресурсами](/ru/plugins/bus/) |
| **Ретрансляция** (relay) | Пересылка трафика одного игрока остальным. Её можно фильтровать для отдельных получателей. | [Нативные модули](/ru/plugins/native-modules/) |
| **Водитель, авторитет, спавнер** (driver, authority, spawner) | Спавнер создал машину. Водитель сидит за рулём. Авторитет — игрок, чья игра считает машину и рассылает её состояние; обычно это водитель. | [Игроки и машины](/ru/plugins/players-and-vehicles/) |
