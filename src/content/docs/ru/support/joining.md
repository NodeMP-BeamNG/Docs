Вход идёт по этапам, и у каждого своё уведомление об ошибке. **Заголовок** говорит, какой этап не
удался; строка под ним — причина, слово в слово от сервера или помощника лаунчера: ищите её на этой
странице. Если лаунчер знает, как помочь, в уведомлении будет совет и кнопка («Обновить сейчас»,
«Копировать»). Все неудачные входы остаются в центре уведомлений — колокольчик на панели слева.

| Этап | Что показывает лаунчер | Если не удалось |
|---|---|---|
| Клиентский мод | `Checking client mod`, `Downloading client mod N%` | [Клиентский мод](#клиентский-мод) |
| Игра | `Starting BeamNG.drive`, `Waiting for BeamNG.drive` | [Запуск игры](#запуск-игры) |
| Соединение | `Contacting the server` | [Подключение](#подключение) |
| Проверки сервера | `Checking your game files`, загрузка модов сервера | [Сервер не пустил](#сервер-не-пустил) |
| В игре | панель сессии | [Сессия завершилась в игре](#сессия-завершилась-в-игре) |

Шаги входа лаунчер пока показывает по-английски — так они и приведены.

## Клиентский мод

Перед каждым входом лаунчер проверяет клиентский мод, `NodeMP.zip`, и скачивает новую версию. Если
мод уже установлен, а проверка не удалась, вход продолжится с установленной версией — вы увидите
только предупреждение «Клиентский мод не обновился» / «Входим с установленной версией». Ошибки ниже
останавливают вход, только если мода нет совсем.

| Сообщение | Причина | Что делать |
|---|---|---|
| **Не удалось войти** · `client mod is not installed and the directory is unreachable` | Первый вход; `api.nodemp.com` не ответил. | Проверьте интернет и войдите снова. |
| **Не удалось войти** · `client mod is not installed and no release has been published yet` | Первый вход; релиза клиентского мода ещё нет. | Дождитесь релиза. |
| **Не удалось войти** · `could not start the download: …`, `the download server returned …`, `the download stopped: …`, `the download was N bytes, the release says M`, `the download is larger than the release says` | Сервер с файлом недоступен, или загрузка оборвалась. | Проверьте соединение, VPN или прокси; войдите снова. |
| **Не удалось войти** · `the downloaded client mod does not match the published checksum` | Файл скачался повреждённым. | Войдите снова. |
| **Не удалось войти** · `LOCALAPPDATA is not set, so BeamNG's user folder cannot be found` | Нет переменной окружения Windows. | Выйдите из учётной записи Windows и войдите снова. |
| **Не удалось проверить клиентский мод** · `could not replace …\NodeMP.zip (is BeamNG.drive running?): …` | Игра держит старый архив открытым. | Закройте BeamNG.drive, затем **Настройки → Лаунчер → Клиентский мод → Проверить**. |

Если в ошибке упоминается `…\mods\multiplayer` или `NodeMP.zip.part`, лаунчер не может писать в
папку пользователя BeamNG: освободите место на диске и проверьте права на
`%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\multiplayer\`.

## Запуск игры

| Сообщение | Причина | Что делать |
|---|---|---|
| **Не удалось запустить сессию** · `could not start …: …` | Windows не дала запустить помощника лаунчера — обычно мешает антивирус. | Добавьте папку лаунчера `%LOCALAPPDATA%\NodeMP` в исключения антивируса или переустановите с [nodemp.com/download](https://nodemp.com/download). |
| **Сетевой помощник лаунчера остановился** · `Failed to find the game please launch it. Report this if the issue persists code 8` | Игра не найдена. `code 8` — метка поиска игры, а не код ошибки. | Укажите папку игры в **Настройки → Игра** или один раз запустите игру через Steam. |
| **Сетевой помощник лаунчера остановился** · `Failed to Launch the game! launcher closing soon.` | Игра не запустилась ни через Steam, ни через `Bin64\BeamNG.drive.x64.exe`. | Проверьте целостность файлов в Steam и путь в **Настройки → Игра**. |
| Вход долго стоит на `Starting BeamNG.drive` или `Loading BeamNG.drive` | Холодный запуск BeamNG занимает время. | Подождите. Если игра так и не появилась, приложите `launcher.log` к сообщению ([Логи](/ru/support/logs/)). |

**Настройки → Игра** показывают свои сообщения под путём:

- `Could not find a BeamNG.drive install. Browse to it, or launch the game once so Steam writes its path.`
  — нажмите **Обзор** и выберите папку игры или один раз запустите игру через Steam и нажмите
  **Найти**.
- `No Bin64\BeamNG.drive.x64.exe in this folder` — это не корневая папка игры; выберите ту, в
  которой лежит `Bin64\`.

## Подключение

| Сообщение | Причина | Что делать |
|---|---|---|
| **Не удалось подключиться** · `Could not reach the server` | По этому адресу никто не отвечает: сервер выключен, порт закрыт, мешает файрвол. | Обновите список. Если сервер ваш — проверьте порт `30814` TCP и UDP. |
| **Не удалось подключиться** · `DNS Lookup Failed` | Имя в адресе прямого подключения не находится. | Проверьте написание или введите IP. |
| **Не удалось подключиться** · `server certificate fingerprint mismatch` | У сервера, на который вы заходили по адресу, сменился сертификат. | Спросите хоста, переустанавливал ли он сервер. Если да — удалите строку сервера из `known_servers.json` в папке кэша лаунчера (**Настройки → Лаунчер → Скачанный контент → Открыть**). |
| **Не удалось подключиться** · `TLS handshake failed: …`, `server presented no certificate` | На этом порту отвечает не сервер NodeMP, или соединение оборвалось на полпути. | Проверьте адрес и порт; попробуйте снова. |

## Сервер не пустил

Заголовок уведомления — **Сервер не пустил в игру**, под ним причина от сервера. Отказы из-за
версий и строгой проверки лаунчер объясняет своими словами (по-английски) и добавляет совет;
исходный текст сервера — под **Подробности**. Все причины, которые может прислать сервер, — в
разделе [Коды ошибок](/ru/support/error-codes/#отказы-сервера-и-причины-кика).

### Аккаунт и билет

| Причина | Что случилось | Что делать |
|---|---|---|
| `This server requires a NodeMP account: sign in to the launcher and join again` | Вы в Test Drive, а сервер пускает только с аккаунтом. | **Настройки → Аккаунт → Войти** или фильтр *Без аккаунта*. |
| `Your join ticket was not accepted (join ticket invalid or expired). Join again from the launcher to get a new one` | Билет одноразовый и живёт около минуты. | Войдите снова. |
| `The server could not verify your account with the directory (…). Try again in a moment` | Сервер не смог связаться с NodeMP, чтобы проверить вас. | Попробуйте чуть позже. |

### Версии

| Показано как | Что случилось | Что делать |
|---|---|---|
| `This server needs a newer launcher — update now` | Сервер говорит на более новой версии протокола. | Нажмите **Обновить сейчас**: лаунчер обновится, перезапустится и снова зайдёт на этот сервер. Если сам обновиться не может — установите свежий с [nodemp.com/download](https://nodemp.com/download). |
| `This server runs an older NodeMP server (protocol v21; this launcher speaks v22)` | Сервер отстал от вашего лаунчера. | С вашей стороны ничего — обновиться должен хост. |
| `Your NodeMP mod is out of date for this server (it speaks wire protocol …, the server …). Reinstall it from the launcher.` | Клиентский мод не той версии, которую ждёт сервер. | Закройте игру, **Настройки → Лаунчер → Клиентский мод → Проверить**, войдите снова. |

### Файлы игры

| Причина или показано как | Что случилось | Что делать |
|---|---|---|
| `Your BeamNG install does not match the game's own file list (3 files differ). Verify the game's files in Steam and try again. …` | Сервер проверяет файлы игры, и ваши отличаются от списка самой игры. | В Steam: BeamNG.drive → *Свойства → Установленные файлы → Проверить целостность файлов игры*. |
| `Your game files do not match this server's reference (3 problems) · vehicles/pickup/pickup.jbeam` | **Строгий** сервер: установка или папка пользователя отличается от чистой установки. | См. [Серверы со строгой проверкой](/ru/support/strict-servers/). |
| `This server's reference manifest changed — join again` | Хост заменил эталон сервера. | Войдите снова. |
| `This server requires a strict check of your BeamNG install but has no integrity manifest to check it against. …` | Сервер неправильно настроен. | Сообщите хосту. |

### Контент сервера

| Причина | Что случилось | Что делать |
|---|---|---|
| `Invalid mod "…"`, `Failed to verify "…"`, `Server cannot find …` | Мод, который присылает сервер, повреждён или отсутствует на сервере. | Сообщите хосту. Удаление файла в разделе **Контент** заставит скачать его заново. |

### Остальное

| Причина | Что делать |
|---|---|
| `Server full!` | Фильтр *Есть места* — или подождите. |
| `You are banned from this server` | Обратитесь к хосту. Если у бана есть причина, вместо этого текста будет она. |
| `The server is still starting, please try joining again later.` | Попробуйте через минуту. |
| `Connection refused` | Вас не пустил один из плагинов сервера. Обратитесь к хосту. |

## Сессия завершилась в игре

Если сессия завершилась во время игры, игра показывает *The session has ended* с причиной, а
лаунчер возвращается с уведомлением **Сессия завершена** и той же причиной. Без причины — значит,
BeamNG.drive просто закрыли.

| Причина | Что случилось | Что делать |
|---|---|---|
| `Kicked`, `Banned` или слова хоста | Вас удалил хост или плагин. | Обратитесь к хосту. |
| `Server shutdown` | Сервер остановлен. | Подождите, пока хост его поднимет. |
| `Replaced` | На этот сервер зашли с вашего аккаунта — с другого ПК или из второго лаунчера. (Следующий релиз сервера.) | Не играйте из двух мест сразу; если это были не вы — смените пароль. |
| `Resume rejected`, `Resume rejected: too many failed attempts, try again later` | Соединение оборвалось, и сервер не дал лаунчеру восстановить сессию. (Следующий релиз сервера.) | Войдите снова; после нескольких неудач подождите минуту. |
| `Game files changed while you were playing and no longer match this server's reference (1 problem). …` | Строгий сервер перепроверил файлы и нашёл изменение. | См. [Серверы со строгой проверкой](/ru/support/strict-servers/#во-время-игры). |
| `Socket Closed Code 1`, `Invalid Socket`, `Malformed frame from server` | Соединение с сервером оборвалось: сеть, VPN или сам сервер. | Войдите снова; проверьте соединение. |
