## Вход

Сообщения окна входа и что с ними делать — на странице
[Аккаунт и вход](/ru/players/sign-in/#если-что-то-пошло-не-так). Если там написано
*Вход через браузер не удался:*, текст после двоеточия объясняет причину:

| Текст после двоеточия | Причина | Что делать |
|---|---|---|
| `could not reach the directory: …` | Нет связи с `api.nodemp.com`. | Проверьте соединение и VPN. |
| `the directory returned …` | Ошибка на стороне NodeMP. | Попробуйте через несколько минут. |
| `unexpected reply from the directory: …` | Ответил кто-то другой — прокси, страница входа в Wi-Fi гостиницы или кафе. | Откройте в браузере любой сайт, затем попробуйте снова. |
| `could not save the sign-in: …`, `could not reach the credential store: …` | Диспетчер учётных данных Windows не сохранил вход. | Войдите снова. Пока это не заработает, вход не запоминается между запусками. |

Окно **Аккаунт заблокирован** значит, что заблокирован сам аккаунт: в нём причина, срок и кнопка
**Подать апелляцию**. См. [Блокировка аккаунта](/ru/players/sign-in/#блокировка-аккаунта).

## Список серверов пуст

- **Соединение потеряно** при запуске — *Не удалось загрузить список серверов. Проверьте
  подключение к интернету.* Нажмите **Попробовать снова** или **Продолжить без списка**: прямое
  подключение работает и так.
- **Не удалось связаться с NodeMP** после **Обновить** — с адресом, к которому обращался лаунчер.
  То же самое, но позже.
- *Серверов нет* / *Сейчас никто не держит сервер.* — NodeMP ответил, список действительно пуст. С
  вашей стороны всё в порядке.
- *Под эти фильтры ничего не подходит* — нажмите **Сбросить все фильтры**. Избранное и недавние
  показывают только серверы, которые сейчас онлайн.
- Сервера, который точно работает, нет в списке — он закрытый, без ключа или перестал сообщать о
  себе NodeMP. Зайдите на него через **Прямое подключение**.

Вход, пока NodeMP недоступен, идёт без билета, и подтвердить, кто вы, некому: сервер с *Нужен
аккаунт* такой вход не примет, сервер с Test Drive пустит вас как непроверенного гостя, а сервер без
ключа примет имя как есть.

## Обновления лаунчера

| Сообщение | Причина | Что делать |
|---|---|---|
| **Не удалось проверить обновления лаунчера** | Нет связи с NodeMP. | Ничего срочного: входить можно, проверка повторится перед следующим входом. |
| **Обновление установится после выхода с сервера** | Во время сессии обновление не ставится никогда. | Выйдите с сервера — тогда оно и установится. |
| **Новее этой версии лаунчера пока не выпущено** | Сервер просит лаунчер новее любого релиза. | Дождитесь релиза. |
| **Не удалось установить обновление лаунчера** · `the downloaded installer does not match the published checksum` | Файл скачался повреждённым. | Попробуйте снова. |
| **Не удалось установить обновление лаунчера** · `the download stopped (…); it resumes on the next try`, `the download stopped at N of M bytes; it resumes on the next try` | Загрузка оборвалась. | Попробуйте снова — она продолжится с места обрыва. |
| `Эта копия не обновляется сама: …` и `this copy was not installed by the NodeMP installer; update it from the download page` (в **Настройки → Лаунчер → Обновления**) | Копия установлена не установщиком. | Установите лаунчер с [nodemp.com/download](https://nodemp.com/download). |
| **Обновление до v… не установилось** / *Остаётся v…. Обновление будет предложено снова.* | Установщик не завершил работу. | Ничего — обновление предложат снова. Если ошибка повторяется, установите со страницы загрузки. |
| **Не удалось вернуть предыдущую версию** | Прошлую версию не удалось переустановить; строка под заголовком говорит почему. | Установите текущий лаунчер со страницы загрузки. |

## Другие сообщения

| Сообщение | Что делать |
|---|---|
| **Не удалось удалить файл** · `could not remove …: …` | Архив занят игрой: закройте BeamNG.drive и удалите снова. |
| **Не удалось открыть браузер** | Скопируйте ссылку (**Скопировать** в окне входа). |
| **Не удалось открыть папку** | Откройте её в проводнике вручную — пути есть на странице [Логи и отчёты](/ru/support/logs/). |
| **Не удалось изменить автозапуск** | Windows не дала изменить настройку. Включите или выключите NodeMP в *Автозагрузке* параметров Windows. |
