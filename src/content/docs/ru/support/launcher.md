## Вход

Подробные рекомендации по авторизации собраны в руководстве [Аккаунт и вход](/ru/players/sign-in/#если-что-то-пошло-не-так).

Если в окне авторизации появляется надпись *Вход через браузер не удался:*, текст после двоеточия сразу указывает на причину:

| Сообщение после двоеточия | Что произошло | Как решить |
|---|---|---|
| `could not reach the directory: …` | Нет устойчивой связи с сервисом `api.nodemp.com`. | Проверьте подключение к интернету или отключите конфликтующий VPN. |
| `the directory returned …` | Временный сбой на стороне серверов NodeMP. | Подождите пару минут и попробуйте войти снова. |
| `unexpected reply from the directory: …` | Вместо NodeMP ответил сторонний сервис (например, страница авторизации Wi-Fi в кафе или отели, либо локальный прокси). | Откройте браузер, загрузите любой сайт, чтобы пройти авторизацию в сети, и повторите вход. |
| `could not save the sign-in: …`, `could not reach the credential store: …` | Диспетчер учётных данных Windows не смог сохранить токен авторизации. | Попробуйте войти повторно. До устранения системного сбоя данные входа не будут сохраняться между перезапусками лаунчера. |

Если открылось окно **Аккаунт заблокирован**, значит, действие учётной записи приостановлено администрацией. В окне указаны причина, срок блокировки и доступна кнопка **Подать апелляцию** (подробнее см. в разделе [Блокировка аккаунта](/ru/players/sign-in/#блокировка-аккаунта)).

## Список серверов пуст

Если в каталоге не отображаются серверы, обратите внимание на статус:

- **Соединение потеряно** при старте программы (*Не удалось загрузить список серверов. Проверьте подключение к интернету.*) — нажмите кнопку **Попробовать снова**. Если каталогу мешают сетевые проблемы, можно нажать **Продолжить без списка**: прямое подключение Direct Connect работает даже без каталога.
- **Не удалось связаться с NodeMP** после нажатия кнопки **Обновить** — лаунчер не смог обновить список серверов по указанному адресу. Попробуйте обновить список чуть позже.
- Статус *Серверов нет* или *Сейчас никто не держит сервер.* — связь с сервисом NodeMP работает штатно, просто в данный момент нет активных публичных серверов. На вашем ПК всё в полном порядке.
- Статус *Под эти фильтры ничего не подходит* — активные серверы есть, но скрыты вашими критериями поиска. Нажмите **Сбросить все фильтры**. Вкладки «Избранное» и «Недавние» показывают только те серверы, которые сейчас находятся онлайн.
- Нужного сервера нет в списке, хотя он точно запущен — сервер может быть приватным, работать без регистрационного ключа или временно потерять связь с директорией. Подключитесь к нему через вкладку **Прямое подключение**.

Когда сервис NodeMP временно недоступен, подключение выполняется без серверного билета. В таком режиме сервер с требованием авторизации (*Нужен аккаунт*) отклонит вход, сервер с разрешённым Test Drive примет вас как непроверенного гостя, а локальный сервер без ключа сохранит введённое имя игрока.

## Обновления лаунчера

Лаунчер автоматически проверяет наличие свежих версий программы. Если во время обновления возникла заминка:

| Сообщение | Причина | Что делать |
|---|---|---|
| **Не удалось проверить обновления лаунчера** | Временные проблемы со связью с сервером обновлений NodeMP. | Ничего критичного: играть можно дальше, лаунчер повторит проверку перед следующим запуском. |
| **Обновление установится после выхода с сервера** | Защита от прерывания заезда: файлы лаунчера не обновляются во время активной игры. | Закончите сессию и закройте игру — обновление установится сразу после этого. |
| **Новее этой версии лаунчера пока не выпущено** | Игровой сервер требует версию лаунчера новее официально опубликованной. | Дождитесь публикации следующего релиза. |
| **Не удалось установить обновление лаунчера** · `the downloaded installer does not match the published checksum` | Установочный файл скачался с повреждением. | Попробуйте запустить обновление ещё раз. |
| **Не удалось установить обновление лаунчера** · `the download stopped (…); it resumes on the next try`, `the download stopped at N of M bytes; it resumes on the next try` | Загрузка файла была прервана из-за обрыва соединения. | Нажмите кнопку обновления снова — загрузка продолжится с того места, где остановилась. |
| `Эта копия не обновляется сама: …` и `this copy was not installed by the NodeMP installer; update it from the download page` (в **Настройки → Лаунчер → Обновления**) | Текущая копия программы была запущена без официального инсталлятора. | Установите лаунчер через установщик с [nodemp.com/download](https://nodemp.com/download). |
| **Обновление до v… не установилось** / *Остаётся v…. Обновление будет предложено снова.* | Процесс установщика завершился с ошибкой или был отменён. | При следующем запуске обновление будет предложено повторно. При постоянных сбоях скачайте свежий инсталлятор вручную. |
| **Не удалось вернуть предыдущую версию** | Не удалось выполнить автоматический откат к предыдущей сборке. | Скачайте актуальный установщик с официального сайта. |

## Другие сообщения

| Сообщение | Что делать |
|---|---|
| **Не удалось удалить файл** · `could not remove …: …` | Файл мода заблокирован запущенной игрой. Закройте BeamNG.drive и повторите удаление. |
| **Не удалось открыть браузер** | Скопируйте ссылку вручную (кнопка **Скопировать** в диалоге входа) и откройте её в любом браузере. |
| **Не удалось открыть папку** | Откройте нужный каталог через Проводник Windows самостоятельно. Точные пути указаны на странице [Логи и отчёты](/ru/support/logs/). |
| **Не удалось изменить автозапуск** | Windows заблокировала изменение параметров автозагрузки. Включите или отключите NodeMP вручную в системном меню *Параметры → Приложения → Автозагрузка*. |
