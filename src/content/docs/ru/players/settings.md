Настройки живут в двух местах: в разделе **Settings** лаунчера — всё вокруг сессии, и на
странице **NodeMP** в Options игры — всё внутри неё. И те и другие сохраняются сразу при
изменении. Одна настройка процесса-хелпера не имеет элемента управления ни там, ни там и живёт
в его [`Launcher.cfg`](#конфигурация-хелпера-launchercfg).

## Настройки лаунчера

Шестерёнка внизу боковой панели открывает три страницы.

**Game**

- **Where BeamNG.drive is installed** — пусто означает *Found automatically*. **Browse** выбирает
  папку, **Find it** ищет заново; строка под заголовком сообщает результат, например
  `Version 0.39.4.0` или `No Bin64\BeamNG.drive.x64.exe in this folder`.
- **Graphics mode** — *Direct3D 12* (по умолчанию в BeamNG 0.39), *Vulkan* или *Direct3D 11*;
  передаётся игре как `-gfx`.

**Launcher**

- **Start with Windows** — добавляет запись `NodeMP` в ключ Run вашего пользователя.
- **Close the launcher once the game starts** — по умолчанию выключено: окно скрывается на время
  сессии и возвращается, когда BeamNG.drive закрывается или сервер завершает сессию. Если включить, окно закрывается окончательно, а
  процесс, который передаёт ваш трафик, продолжает работать.
- **Folders → Downloaded content** — кеш хелпера с контентом с серверов и его размер; **Open**
  открывает папку. **Folders → Logs** — куда пишется `launcher.log`; приложите его, когда
  сообщаете о проблеме.
- **Client mod** — установленная версия и результат последней проверки; **Check now** повторяет
  проверку. См. [Клиентский мод](/ru/players/install/#клиентский-мод).
- **Reset settings** — возврат к значениям по умолчанию; избранное, недавние серверы и
  загрузки сохраняются.

**Account** — имя, под которым вас видят серверы. После входа: id аккаунта, роли и **Sign out**.
В режиме Test Drive: `Guest · a new name each session, and servers may refuse it` и **Sign in**.

Раздел **Content** в боковой панели показывает этот кеш и позволяет удалять файлы кнопкой
**Remove** (сначала закройте BeamNG: она держит архивы открытыми). Сервер, которому нужен
удалённый файл, скачает его снова.

## Конфигурация хелпера: `Launcher.cfg`

Хелпер — процесс, который передаёт ваш трафик, — читает один JSON-файл из своей папки данных,
записанный со значениями по умолчанию при первом запуске:

```
%LOCALAPPDATA%\com.nodemp.launcher\helper\Launcher.cfg
```

```json
{
    "Port": 4444,
    "Name": "",
    "DefaultServer": "",
    "ServerFingerprint": "",
    "CacheDirectory": "./cache",
    "StrictRecheckMin": 10
}
```

Лаунчер передаёт сервер, ваше имя и билет в командной строке при каждом подключении, так что
`Name`, `DefaultServer` и `ServerFingerprint` — для тех, кто запускает хелпер вручную; `Port` —
командный канал, к которому подключается клиентский мод, а `CacheDirectory` — куда складывается
скачанный контент. Единственный ключ, который стоит менять:

- **`StrictRecheckMin`** — на сервере с `VerifyGame = "strict"`
  ([Строгая проверка](/ru/hosting/strict-verification/)) — сколько минут проходит между плановыми
  перепроверками ваших файлов игры хелпером во время сессии. По умолчанию `10`; `0` выключает
  расписание; отрицательное или нецелое значение игнорируется с записью
  `Ignoring StrictRecheckMin "…": expected a whole number of minutes (0 = no scheduled re-check)`
  в `launcher.log`, и используется значение по умолчанию. На серверах ниже `strict` ключ не
  действует.

Перепроверка — та же строгая проверка, что и при подключении, — папка игры, оглавление каждого
архива и пользовательская папка — с одним отличием: бинарники (`Bin64\`, `BinLinux\`, файлы
`.exe` в папке игры) сравниваются только по размеру, без хеширования. Библиотека, которую
работающая игра уже загрузила, не может изменить поведение игры до следующего запуска, а
следующий запуск снова выполняет полную проверку на входе; сервер также может в любой момент
запросить полную (`player:verify`), и такой запрос хеширует всё всегда. Перепроверка, которая
ничего не нашла, серверу не отправляется. Та, которая нашла изменение, отправляется, и сервер
тогда завершает сессию с
`Game files changed while you were playing and no longer match this server's reference (N problems). …`
([Устранение неполадок](/ru/players/troubleshooting/#строгие-серверы)). Помимо расписания
хелпер перепроверяет, когда видит изменения файлов под `content\`, `scripts\`, `lua\` и `ui\`
установки или под `vehicles\`, `levels\`, `lua\`, `ui\` и `art\` пользовательской папки, не чаще
раза в минуту; расписание существует для того, чего наблюдатель не покрывает.

`Launcher.cfg`, который не является корректным JSON, останавливает хелпер с
`Config failed to parse make sure it's valid JSON!` ([Коды ошибок](/ru/reference/error-codes/#коды-выхода-хелпера)).

## В игре: Options → NodeMP

В боковой панели **Options** игры появляется пункт **NodeMP** (он же в меню паузы, на вкладке
модов: *Настройки NodeMP*). В заголовке — версии мода и лаунчера.

| Раздел | Настройки |
|---|---|
| Геймплей и синхронизация | *Сила коррекции* (0,25–2×) и *Порог телепорта* (0,25–4×) для машин других игроков; *Гост при ресете (эта машина)* (1,5 с без столкновений на вашем экране; сервер может переопределить). |
| Никнеймы | *Скрывать свой никнейм*, *Тег «Empty» на пустых машинах*, *Показывать расстояние*, *Прятать теги за объектами*, *Дистанция затухания* (0–2000 м, по умолчанию 100). |
| Маркеры | *Маркеры неспавненных машин*, *Маркеры удалённых машин*. |
| Машина | *Мои машины: доступ (0/1/2)* — 0 открытая, 1 только пассажиры, 2 только вы; *Триггеры моих машин — другим*; *Имя на номерах*; *Защита конфигов*; *Авто-применение чужих конфигов* (выкл.: игрок, изменивший машину, подсвечивается — кликните, чтобы применить); *3D-головы игроков в машинах*; *Маркеры свободной камеры*. |
| Моды | *Использовать мои локальные моды в мультиплеере* — по умолчанию выкл.; сервер тоже должен это разрешить. |
| Чат и интерфейс | *Чат-оверлей в игре* — дополнительное ImGui-окно чата и списка игроков, по умолчанию выкл. |
| Экспериментальное и отладка | За переключателем *Включить экспериментальные функции*: *Синхронный нод-граббер (Ctrl)*, *Разрешить тянуть мои машины (Ctrl)*, *Диагностика синхронизации позиций*, *Логирование синхронизации состояния*, *Подробные логи*, *Отключить применение состояния*. Держите их выключенными, если не ищете причину бага. |

**Инструменты** открывают **Консоль диагностики (ImGui)**: вкладки: сессия, игроки, машины,
чат, сеть, очередь, события, настройки, отладка. *Мои машины: доступ*, *Триггеры моих машин — другим* и *Разрешить
тянуть мои машины* отправляются на сервер как ваша политика машин и применяются к каждой
машине, которую вы спавните.

## Чат и список игроков

Интерфейс в игре по умолчанию — два UI-приложения BeamNG: **чат** (затухающие строки поверх
мира; наведите курсор на угол, чтобы увидеть историю) и **панель сессии** (название сервера,
пинг, число игроков со списком под ним, удержание **Leave**). В сообщениях работают
caret-коды: `^0`–`^9` и `^a`–`^f` — цвета, `^#RRGGBB`, `^l` — жирный, `^o` — курсив, `^n` —
подчёркивание, `^m` — зачёркивание, `^r` — сброс.

*Чат-оверлей в игре* добавляет третье окно, `NodeMP Chat`, со своей вкладкой настроек
(*Theming* — цвет каждого элемента; *General* — *Inactive fade*, *Fade time*, *Fade when
collapsed*, *Show on message*, *Keep active on Enter*). Его кнопка **Save** записывает эти
настройки в файл в пользовательской папке BeamNG:

```
%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\settings\nodemp\chat.json
```

Удалите файл, чтобы вернуть оверлей к значениям по умолчанию; файл от более старой сборки при
загрузке накладывается на текущие значения по умолчанию.

## Клавиши

Мод поставляет эти привязки в категории *gameplay* раздела **Options → Controls**, где их можно
изменить:

| По умолчанию | Действие | Что делает |
|---|---|---|
| `T` | NodeMP: Chat | Открывает чат для ввода. Enter отправляет, Esc закрывает. |
| `Tab` | NodeMP: Player list | Переключает список игроков, как щелчок по числу игроков. |
| не назначено | NodeMP: Diagnostics window | Открывает консоль диагностики. |
| не назначено | NodeMP: Toggle debug chat | Переключает ImGui-окно чата. |
| не назначено | NodeMP: Join grabbed node (alias) | То же, что игровое действие *Node grabber: fix node*. |

Пока клавиатура у чата, машина её не получает: карты действий машины отключены, пока вы не
нажмёте Esc или не отправите пустую строку.
