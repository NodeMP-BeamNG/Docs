Все настройки разделены на две части: меню **Настройки** в лаунчере отвечает за запуск и подготовку к сессии, а страница **NodeMP** в опциях игры регулирует поведение машин и интерфейс прямо во время заезда. Любые изменения применяются мгновенно.

## Настройки лаунчера

Чтобы открыть настройки, нажмите на значок шестерёнки в левой панели лаунчера. Здесь есть три вкладки:

### Игра

| Параметр | Что делает |
|---|---|
| **Где установлена BeamNG.drive** | Путь к папке игры. Если поле не заполнено, лаунчер находит игру сам. Кнопка **Обзор** позволяет выбрать каталог вручную, а **Найти** — запустить поиск заново. Строка под заголовком показывает найденную версию, например `Version 0.39.4.0`. |
| **Графический режим** | Выбор графического API: *Direct3D 12*, *Vulkan* или *Direct3D 11*. Игра запустится в выбранном режиме без лишних диалоговых окон. |

### Лаунчер

| Параметр | Что делает |
|---|---|
| **Язык** | Язык интерфейса самого лаунчера. Сообщения серверов и внутриигровые тексты отображаются на языке оригинала. |
| **Удержание для игры** | Защита от случайных кликов: для входа нужно зажать кнопку «Зажмите для игры». Если выключить опцию, подключение происходит по обычному клику. |
| **Запускать вместе с Windows** | Автоматический старт NodeMP при входе в систему. |
| **Закрывать лаунчер после запуска игры** | По умолчанию окно лаунчера сворачивается на время сессии и открывается после выхода. При включении опции окно закрывается полностью, а фоновый процесс сетевого помощника продолжает работу. |
| **Папки → Скачанный контент** | Список и объём модификаций, загруженных с серверов. Кнопка **Открыть** открывает папку с модами в проводнике. |
| **Папки → Логи** | Расположение файла логов (пригодится, если понадобится приложить лог к отчёту об ошибке). |
| **Клиентский мод** | Версия установленного мода и кнопка **Проверить** для быстрой ручной проверки. |
| **Обновления** | Канал обновлений (*Релиз* или *Бета*), автопроверка и возможность отката — подробнее см. в разделе [Обновления лаунчера](/ru/players/install/#обновления-лаунчера). |
| **Сброс** | Возвращает настройки лаунчера к значениям по умолчанию. Избранное, список недавних серверов и скачанные файлы при этом сохраняются. |

### Аккаунт

Показывает ваш подтверждённый никнейм и кнопки **Управлять на сайте** и **Выйти** (в режиме Test Drive — **Войти**). Подробнее читайте на странице [Аккаунт и вход](/ru/players/sign-in/).

## Скачанные моды серверов

Во вкладке **Контент** на левой панели лаунчера собраны все модификации, которые вы скачали при заходе на серверы: имя архива, его размер и дата загрузки.

Здесь есть поиск и кнопка **Открыть папку**. Кнопка **Удалить** позволяет быстро очистить диск от ненужного контента (перед удалением убедитесь, что BeamNG.drive закрыта). Если удалённый мод снова потребуется для игры, лаунчер без проблем скачает его при следующем подключении.

## В игре: Options → NodeMP

В самой BeamNG.drive в меню **Options** появляется раздел **NodeMP** (его также можно открыть из меню паузы через *Mods → NodeMP settings*). Меню оформлено на английском языке, поэтому ниже приведены оригинальные названия пунктов с краткими пояснениями:

| Раздел | Доступные параметры |
|---|---|
| Gameplay & sync | Тонкая настройка сетевой синхронизации чужих машин. *Correction strength* (сила коррекции) и *Teleport threshold* (порог телепортации) регулируют плавность интерполяции при сетевых задержках. Пункт *Hold other cars tightly* (выключен по умолчанию) делает траектории чужих машин стабильнее в заносах за счёт чуть более резкой реакции на ускорение и торможение. Опция *Steering look-ahead* сглаживает повороты колёс с упреждением пинга, а *Ghost cars on reset* даёт машине 1,5 секунды неуязвимости без коллизий после сброса. |
| Name tags | Настройка меток над автомобилями: можно скрыть свой ник (*Hide my own nametag*), метку «Empty» на незанятых машинах, отображение дистанции до игрока, а также задать дальность видимости меток (*Fade distance*). |
| Markers | Отображение маркеров для машин других участников, которые ещё загружаются на карту или были удалены. |
| Vehicle | Права доступа к вашим машинам (*My cars: access*: 0 — открыта для всех, 1 — только для пассажиров, 2 — только для вас), разрешение использовать триггеры салона, никнейм на номерных знаках, защита конфигураций и автоматическое применение чужого тюнинга. |
| Mods | Пункт *Use my local mods in multiplayer* разрешает использовать личные модификации в онлайне (по умолчанию выключен и требует одобрения со стороны сервера). |
| Chat & UI | Включение альтернативного внутриигрового окна чата (*In-game chat overlay*). |
| Experimental & debug | Раздел экспериментальных возможностей: синхронный захват узлов на Ctrl, разрешение хватать ваши узлы и отладочные режимы. Без необходимости включать их не стоит. |

Кнопка **Tools** открывает консоль живой диагностики: там можно посмотреть статус сессии, пинг, входящие пакеты, события и активные автомобили в реальном времени.

## Чат и список игроков

По умолчанию в игре отображаются два удобных элемента NodeMP:

- **Чат** — полупрозрачные строки поверх мира, которые плавно исчезают со временем. Чтобы просмотреть недавние сообщения, наведите курсор на угол чата.
- **Панель сессии** — в верхнем углу экрана: название сервера, текущий пинг, количество участников с раскрывающимся списком и кнопка выхода **Leave** (нужно удерживать).

В тексте сообщений можно использовать цветовые коды: `^0`–`^9` и `^a`–`^f` для базовых цветов, `^#RRGGBB` для произвольного HEX-оттенка, а также стили: `^l` (жирный шрифт), `^o` (курсив), `^n` (подчёркнутый), `^m` (зачёркнутый) и `^r` (сброс форматирования).

Если включить расширенный чат (*In-game chat overlay*), появится настраиваемое окно `NodeMP Chat`. Его настройки хранятся в файле:

```
%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\settings\nodemp\chat.json
```

Если удалить этот файл, окно чата вернётся к стандартному оформлению.

## Клавиши

Клавиши управления NodeMP настраиваются в меню игры **Options → Controls** в категории *gameplay*:

| Клавиша по умолчанию | Действие | Описание |
|---|---|---|
| `T` | NodeMP: Chat | Открыть окно чата (Enter отправляет сообщение, Esc закрывает). |
| `Tab` | NodeMP: Player list | Показать или скрыть список игроков на сервере. |
| не назначено | NodeMP: Diagnostics window | Открыть окно системной диагностики. |
| не назначено | NodeMP: Toggle debug chat | Показать или скрыть окно расширенного чата-оверлея. |
| не назначено | NodeMP: Join grabbed node (alias) | Зафиксировать захваченный узел (аналог действия *Node grabber: fix node*). |

Когда открыто окно ввода чата, управление автомобилем временно отключается, чтобы нажатия клавиш не мешали вождению.

## Для продвинутых: Launcher.cfg

Фоновый помощник лаунчера — процесс, который передаёт сетевой трафик во время игры, — читает свои настройки из файла:

```
%LOCALAPPDATA%\com.nodemp.launcher\helper\Launcher.cfg
```

Адреса серверов, токены сессии и имя игрока лаунчер передаёт сам, поэтому трогать этот файл почти никогда не нужно. Один параметр может пригодиться:

- **`StrictRecheckMin`** — на строгих серверах задаёт интервал (в минутах) между автоматическими перепроверками файлов игры во время сессии. По умолчанию `10`; значение `0` отключает плановые перепроверки (на обычных серверах параметр ни на что не влияет).

Если помощник обнаружит изменённые файлы игры посреди сессии, сервер завершит её. Следите, чтобы `Launcher.cfg` оставался корректным JSON, иначе помощник не запустится (см. [Коды ошибок](/ru/support/error-codes/#коды-выхода-помощника)).
