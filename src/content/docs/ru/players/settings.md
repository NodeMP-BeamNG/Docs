Настройки живут в двух местах: **Настройки** лаунчера — всё, что вокруг сессии, и страница
**NodeMP** в опциях игры — всё, что внутри неё. Изменения сохраняются сразу.

## Настройки лаунчера

Шестерёнка внизу панели слева открывает три вкладки.

### Игра

| Настройка | Что делает |
|---|---|
| **Где установлена BeamNG.drive** | Пусто — путь найдётся автоматически. **Обзор** выбирает папку, **Найти** ищет заново. Строка под заголовком показывает результат, например `Version 0.39.4.0`. |
| **Графический режим** | *Direct3D 12* (по умолчанию в BeamNG 0.39), *Vulkan* или *Direct3D 11* (запасной, если D3D12 не работает). Игра сразу запускается в нём и ничего не спрашивает. |

### Лаунчер

| Настройка | Что делает |
|---|---|
| **Язык** | Язык лаунчера. Тексты серверов и игры показываются так, как их написали. |
| **Удержание для игры** | Включено: «Играть» нужно зажать на 0,4 с и отпустить — без случайных входов. Выключено: вход одним нажатием. |
| **Запускать вместе с Windows** | Открывать NodeMP при входе в Windows. |
| **Закрывать лаунчер после запуска игры** | По умолчанию выключено: окно прячется на время игры и возвращается, когда вы выходите. Включено: окно закрывается, а процесс, который держит соединение, остаётся. |
| **Папки → Скачанный контент** | Моды серверов, которые скачал лаунчер, и их объём. **Открыть** — открыть папку. |
| **Папки → Логи** | Где лежит `launcher.log`. Приложите его к сообщению о проблеме. |
| **Клиентский мод** | Установленная версия и результат последней проверки; **Проверить** — проверить сейчас. |
| **Обновления** | Канал (*Релиз* или *Бета*), автоматическая проверка, возврат к прошлой версии — см. [Обновления лаунчера](/ru/players/install/#обновления-лаунчера). |
| **Сброс** | Вернуть значения по умолчанию. Избранное, недавние серверы и загрузки останутся. |

### Аккаунт

Имя, под которым вас видят серверы, и кнопки **Управлять на сайте** и **Выйти** (в Test Drive —
**Войти**). Подробнее — на странице [Аккаунт и вход](/ru/players/sign-in/).

## Скачанные моды серверов

Раздел **Контент** на панели слева — всё, что прислали серверы: файл, размер и когда скачан. Есть
поиск и **Открыть папку**. **Удалить** освобождает место; перед этим закройте игру — пока она
запущена, архив занят. Серверу, которому нужен удалённый файл, лаунчер скачает его снова при
следующем входе.

## В игре: Options → NodeMP

В боковой панели **Options** игры появляется пункт **NodeMP** (он же в меню паузы: *Mods →
NodeMP settings*). Страница на английском — ниже подписи даны так, как их показывает игра, с
переводом в скобках.

| Раздел | Настройки |
|---|---|
| Gameplay & sync | *Correction strength* (сила коррекции, 0,25–2×) и *Teleport threshold* (порог телепорта, 0,25–4×) — для машин других игроков. *Hold other cars tightly* (плотно держать чужие машины; выкл. по умолчанию): чужие машины точнее в поворотах и заносах, но резче реагируют, когда водитель трогает газ, тормоз или руль. *Steering look-ahead (experimental)* (упреждение руля; выкл.): колёса чужих машин поворачиваются чуть раньше, на половину сетевой задержки. *Ghost cars on reset (this machine)* (призрак при сбросе): 1,5 с без столкновений на вашем экране; сервер может переопределить. |
| Name tags | *Hide my own nametag* (скрыть свой ник), *Show 'Empty' on empty cars* (метка «Empty» на пустых машинах), *Show distance on tags* (расстояние в метке), *Hide tags behind objects* (прятать метки за объектами), *Fade distance* (дальность затухания, 0–2000 м, по умолчанию 100). |
| Markers | *Markers for non-spawned cars* (маркеры ещё не появившихся машин), *Markers for deleted cars* (маркеры удалённых машин). |
| Vehicle | *My cars: access (0/1/2)* (доступ к моим машинам): 0 — открыты, 1 — только пассажиры, 2 — только вы. *Others may use my triggers* (другим можно пользоваться триггерами моих машин), *Name on license plates* (имя на номерах), *Protect my configs* (защитить мои конфиги), *Auto-apply others' configs* (сразу применять чужие конфиги; выкл.: игрок, изменивший машину, подсвечивается — щёлкните, чтобы применить), *3D player heads in cars* (3D-головы игроков в машинах), *Freecam player markers* (маркеры игроков в свободной камере). |
| Mods | *Use my local mods in multiplayer* (использовать мои моды в мультиплеере) — выкл. по умолчанию; сервер тоже должен это разрешать. |
| Chat & UI | *In-game chat overlay* (чат-оверлей) — дополнительное окно чата и списка игроков, выкл. по умолчанию. |
| Experimental & debug | За переключателем *Enable experimental features*: синхронный захват узлов машин (Ctrl), разрешение другим захватывать ваши машины и отладочные режимы синхронизации. Не включайте их без нужды — они для поиска ошибок. |

**Tools** открывает консоль диагностики: сессия, игроки, машины, чат, сеть, события и настройки в
реальном времени. *My cars: access*, *Others may use my triggers* и *Allow others to grab my cars*
уходят на сервер как правила для ваших машин и применяются к каждой машине, которую вы ставите.

## Чат и список игроков

По умолчанию в игре два окна NodeMP:

- **чат** — строки поверх мира, которые постепенно гаснут; наведите курсор на угол, чтобы увидеть
  историю;
- **панель сессии** — название сервера, пинг, число игроков со списком и кнопка **Leave**
  (удерживать).

В сообщениях работают цветовые коды: `^0`–`^9` и `^a`–`^f` — цвета, `^#RRGGBB` — любой цвет,
`^l` — жирный, `^o` — курсив, `^n` — подчёркнутый, `^m` — зачёркнутый, `^r` — сброс.

*In-game chat overlay* добавляет третье окно, `NodeMP Chat`, с вкладкой настроек: цвет каждого
элемента и поведение затухания. Кнопка **Save** сохраняет их в файл:

```
%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\settings\nodemp\chat.json
```

Чтобы вернуть оверлей к значениям по умолчанию, удалите этот файл.

## Клавиши

Привязки NodeMP — в категории *gameplay* раздела **Options → Controls**, там их можно изменить:

| По умолчанию | Действие | Что делает |
|---|---|---|
| `T` | NodeMP: Chat | Открыть чат. Enter — отправить, Esc — закрыть. |
| `Tab` | NodeMP: Player list | Показать или скрыть список игроков. |
| не назначено | NodeMP: Diagnostics window | Открыть консоль диагностики. |
| не назначено | NodeMP: Toggle debug chat | Показать или скрыть окно чата-оверлея. |
| не назначено | NodeMP: Join grabbed node (alias) | То же, что игровое *Node grabber: fix node*. |

Пока открыт чат, машина не получает нажатия клавиш — до Esc или отправки пустой строки.

## Для продвинутых: Launcher.cfg

Помощник лаунчера — процесс, который держит соединение во время игры, — читает файл настроек:

```
%LOCALAPPDATA%\com.nodemp.launcher\helper\Launcher.cfg
```

Лаунчер передаёт сервер, имя и билет при каждом входе сам, поэтому большинство ключей файла нужны
только тем, кто запускает помощника вручную. Менять стоит один:

- **`StrictRecheckMin`** — на строгом сервере: через сколько минут помощник заново сверяет файлы
  игры во время сессии. По умолчанию `10`, `0` — без плановых перепроверок. На нестрогих серверах
  не действует.

Перепроверка — та же строгая проверка, что при входе. Если она нашла изменения, сервер завершает
сессию. Кроме расписания помощник перепроверяет игру, когда видит изменения файлов в папках игры
и пользователя, — не чаще раза в минуту. Если `Launcher.cfg` — некорректный JSON, помощник не
запустится (см. [Коды ошибок](/ru/support/error-codes/#коды-выхода-помощника)).
