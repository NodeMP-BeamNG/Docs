Справочник

Сообщения об ошибках

Номеров ошибок в NodeMP нет. Вход останавливает фраза: уведомление лаунчера, отказ или кик от сервера, последняя строка лога помощника. Здесь собраны все такие фразы, а … заменяет часть, которая меняется. Частые случаи по шагам: Если что-то не работает.

Уведомления лаунчера

Заголовок раздела «Уведомления лаунчера»

У уведомления есть заголовок, который называет шаг, и под ним причина. В таблицах они записаны как заголовок · причина. Заголовки лаунчер показывает на языке интерфейса, а причины от помощника и сервера пишет по-английски. Ошибки и предупреждения остаются в центре уведомлений под колокольчиком: кнопка Копировать кладёт их текст в буфер, а Подробности показывают исходные слова сервера или помощника.

Не удалось подключиться · Could not reach the server По этому адресу никто не отвечает: сервер выключен, порт закрыт или мешает брандмауэр. Обновите список. Если это ваш сервер, проверьте, что порт открыт для TCP и UDP.
Не удалось подключиться · DNS Lookup Failed Имя, введённое в прямом подключении, не находится. Проверьте написание или введите IP-адрес.

В карточке сервера нажмите Обновить и подключиться для сервера из списка или Продолжить для прямого подключения, либо удалите строку сервера из known_servers.json в папке кэша лаунчера.
Не удалось подключиться · TLS handshake failed: …, server presented no certificate Ответил не сервер NodeMP, или соединение оборвалось во время рукопожатия. Проверьте адрес и порт и попробуйте снова. Через VPN: Плохое соединение и VPN.

Отказы и кики сервера

Заголовок раздела «Отказы и кики сервера»

При входе лаунчер показывает отказ как Сервер не пустил в игру. Во время сессии игра сообщает, что сессия завершена, и лаунчер возвращается с Сессия завершена. В логе сервера тот же текст записан как <имя> kicked — <причина>.

Отказы из-за версий и файлов игры лаунчер заменяет своим советом, тоже по-английски, часто с кнопкой. Для таких строк указано, что он показывает, а слова сервера открывает кнопка Подробности. Плагины могут кикать своим текстом, и вы увидите его как есть.

Причина Когда Что сделать
Protocol version mismatch: launcher speaks v22, server speaks v21 - update the outdated side У лаунчера и сервера разные версии протокола, в сообщении стоят настоящие номера обеих. Если отстаёт лаунчер, лаунчер показывает This server needs a newer launcher — update now с кнопкой Обновить сейчас. Если отстаёт сервер, показывает This server runs an older NodeMP server (protocol v21; this launcher speaks v22). Обновить сейчас обновит лаунчер и зайдёт снова. Если отстаёт сервер, скажите хосту.
Your NodeMP mod is out of date for this server (it speaks wire protocol …, the server …). Reinstall it from the launcher. У клиентского мода и сервера разные версии протокола, в сообщении стоят обе. Если число мода меньше, закройте игру, нажмите Настройки → Игра → Клиентский мод → Проверить и зайдите снова. Если больше, скажите хосту: отстаёт сервер.
Server full! На сервере столько игроков, сколько он пускает, а в очередь не встать: вы без аккаунта, лаунчер не умеет ждать в очереди, сервера нет в списке или очередь на нём выключена. Включите в списке переключатель Есть места или подождите.
The server is full and so is its join queue В очереди на вход уже ждёт столько игроков, сколько разрешает хост. Лаунчер пишет Сервер заполнен, и очередь на него тоже. Попробуйте позже. Попробуйте позже.
Someone from your address is already in this server's join queue С вашего адреса в очереди уже ждёт столько игроков, сколько разрешает хост, по умолчанию один. Через общее подключение все игроки приходят с одного адреса. Лаунчер пишет Кто-то из вашей сети уже стоит в очереди на этот сервер. Дождитесь, пока тот игрок войдёт, или зайдите с другого подключения.
You did not join after your turn too often; this server's join queue is closed to you until … Очередь подходила несколько раз, а вы уходили, не дойдя до мира. После слова until стоит время по UTC, когда очередь снова откроется. Лаунчер пишет Вы несколько раз не зашли, когда подходила ваша очередь, поэтому очередь на этот сервер закрыта для вас до … и показывает время по вашим часам. Подождите до этого времени. На сервер со свободным местом можно заходить и сейчас.
The server is starting up; join again in a moment. Сервер ещё загружает плагины. Попробуйте через минуту.
Server shutdown Сервер останавливается. Это получают все, кто на нём. Дождитесь, пока хост его поднимет.
You are banned from this server Ваш адрес, аккаунт или установка лаунчера в списке банов сервера, причина не указана. Если хост её указал, вы увидите её. Спросите хоста.
This server requires a NodeMP account: sign in to the launcher and join again Сервер не пускает Test Drive, а вы зашли без аккаунта. Войдите: Настройки → Аккаунт → Войти. Или включите в списке переключатель Без аккаунта.
Your join ticket was not accepted (join ticket invalid or expired). Join again from the launcher to get a new one NodeMP не принял одноразовый билет на вход, в скобках причина. Зайдите снова.
The server could not verify your account with the directory (…). Try again in a moment Сервер не смог связаться с NodeMP, чтобы проверить аккаунт. Попробуйте чуть позже.
Resume rejected Соединение оборвалось, и лаунчер пытался вернуть сессию, а сервер её не принял: сессия уже закончилась или не сошёлся ключ. Зайдите снова.
Resume rejected: too many failed attempts, try again later С вашего адреса слишком много неудачных попыток вернуть сессию за короткое время. Подождите минуту и зайдите снова.

Disconnected by the NodeMP directory (…) NodeMP отключил ваш аккаунт от сервера, в скобках код причины. Зайдите снова. Если повторяется, сообщите об этом в Discord.
Connection refused Плагин не пустил вас и не назвал причину. Если назвал, вы увидите её. Спросите хоста.
Your BeamNG install does not match the game's own file list (3 files differ). Verify the game's files in Steam and try again. … Часть файлов игры отличается от её собственного списка. Число настоящее. Проверьте файлы игры в Steam.

Reconnect so it fetches the current one. Хост заменил эталонный манифест сервера с вашего прошлого входа. Лаунчер показывает This server's reference manifest changed — join again. Зайдите снова.
This server requires the strict check of your BeamNG install, but your launcher ran only 'size'. Update your launcher and try again. Строгий сервер получил результат более лёгкой проверки. Лаунчер показывает This server needs a newer launcher — update now. Обновить сейчас или переустановите лаунчер с nodemp.com/download.
This server requires a strict check of your BeamNG install but has no integrity manifest to check it against. Ask the host to run `Node-Server --gen-integrity <gamedir>` and put the file in the server's integrity folder. Хост включил строгую проверку, а эталонного манифеста у сервера нет. Скажите хосту (Строгая проверка файлов).
This server has integrity manifests for 2 game versions (0.39.4.0, 0.39.3.0) and cannot tell which one you run. Ask the host to keep exactly one manifest in the server's integrity folder. В папке манифестов сервера лежат файлы для нескольких версий игры. Скажите хосту.
Unknown integrity manifest requested Лаунчер попросил манифест, которого у сервера нет: обычно хост только что его заменил. Лаунчер показывает The server would not send its reference manifest. Зайдите чуть позже. Если повторяется, скажите хосту.
Too many integrity manifest requests За одну сессию лаунчер слишком часто просил манифест. Лаунчер показывает The server stopped sending its reference manifest (asked too often). Зайдите чуть позже. Если повторяется, переустановите лаунчер.
This server requires a check of your BeamNG install, which could not be completed: … Проверка не смогла пройти, после двоеточия причина. Лаунчер показывает BeamNG's user folder was not found, Could not download the server's reference manifest, The server's reference manifest is out of date, The server asked for a strict check without a usable reference manifest, The server asked for too many game-file checks at once или Your game files could not be checked. Выполните совет под сообщением и зайдите снова.
Kicked, Kicked by the server, Kicked by module Вас убрал плагин, консоль сервера или нативный модуль, причину не назвали. Спросите хоста.

Коды выхода помощника

Заголовок раздела «Коды выхода помощника»

Если помощник завершится с ошибкой, лаунчер покажет Сетевой помощник лаунчера остановился и последнюю строку его лога, а Подробности начинаются с exit code и номера. Полный лог: %LOCALAPPDATA%\NodeMP\helper\logs\launcher.log.

Код Последняя строка лога Что значит Что сделать
0 game closed - launcher closing soon BeamNG.drive закрыли, сессия закончилась. Ничего.
1 Launcher.cfg is there but cannot be read; check its permissions, or delete it to start from the defaults, Launcher.cfg is not valid JSON; fix it, or delete it to start from the defaults Файл настроек помощника не читается или испорчен. Удалите Launcher.cfg, помощник напишет новый.
1 Cannot create the mod cache …: …. Point CacheDirectory in Launcher.cfg at a folder you can write to. Не удаётся создать папку для скачанных модов. Исправьте права на папку или задайте CacheDirectory в Launcher.cfg.
2 BeamNG.drive was not found. Choose its folder (the launcher's Settings > Game, or --game-dir), or start the game once so it records where it is. Игра не найдена. Помощник завершается через 10 секунд. Укажите папку в Настройки → Игра или один раз запустите игру через Steam.
2 The game could not be started (through Steam, or by its executable); the launcher closes in 5 s. Игру не запустил ни Steam, ни её собственный файл. Проверьте файлы игры в Steam и путь в Настройки → Игра.
5 Another Node-Launcher is already running on port 4444 - closing Второй помощник запущен, пока работает первый. Закройте первый или BeamNG.drive вместе с ним и попробуйте снова.
6 port 4444 is in use by another program … Локальный порт, через который игра связывается с помощником, занят другой программой. Закройте её. Сообщение называет команду, которая покажет, какая это программа.

Проверку файлов игры помощник умеет запускать и отдельно: команду даёт кнопка Копировать под отказом строгого сервера. Она завершается с кодом 0, если всё чисто (game files verified: …), с кодом 1, если есть отличия (game files DIFFER: …), и с кодом 2, если проверить не удалось (cannot read the manifest file …, not a reference manifest: …, could not check: …).
